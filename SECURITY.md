# Security and research data

Do not post images, experiments, identifiers, invitations, session tokens, or vulnerabilities in public issues, pull requests or discussions.

## Reporting a vulnerability

Report vulnerabilities privately on GitHub: open the repository's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/genellect/cytellect/security/advisories/new)). This private report is the only channel; it is visible only to the reporter and the repository administrators. Do not send vulnerability details through public issues, pull requests or other channels.

Include the affected commit or Windows release, the steps to reproduce and the impact. Use synthetic or published data in the reproduction; never attach unpublished research images, measurements, invitations, session tokens or other credentials.

This is an early research prototype. A public UI deployment is not evidence that the analysis server is provisioned or private-image scientific validation is complete. See [operations](docs/security.md).
