# Security and research data

Do not post images, experiments, identifiers, invitations, session tokens, or vulnerabilities in public issues.

For a vulnerability, use GitHub's private report form under Security when enabled on this repository. If unavailable, do not open a public report containing sensitive details; contact the repository owner privately to arrange a channel. No separate support address is currently advertised.

This is an early research prototype. A public UI deployment is not evidence that the analysis server is provisioned or private-image scientific validation is complete. See [operations](docs/security.md).
