## 測定前の選定・除外計画

- 核の縮小を最優先とし、論文で処理による核面積の減少を定量した画像を探す。核小体面積や核/細胞比だけの変化を代用しない。
- 核数は核染色から採用した核の数。生存率や増殖率とは区別する。
- 核小体は U2OS DS6a の untreated と ActD を候補とし、Fig 5A–B の条件と元画像メタデータの対応を確認する。離心率と 5-EU を対象とする。候補なし・判定不能をゼロにしない。
- 各候補についてファイル一覧を固定し、条件・出典の反復ラベルごとにファイル名の辞書順で最初の3視野を候補とする。同じラベルを独立実験回と推定しない。抽出に画素、核数、面積、信号を使わない。
- メタデータ調査用に各条件の先頭ファイルを取得してよい。形態・数値に基づく選び直しはしない。取得履歴と用途を残す。
- 元画像全体を取得し、画素値を変更しない。切り出しが必要な場合は、測定前に共通座標と大きさを追加で固定する。現段階では切り出さない。
- 取得破損・ハッシュ不一致は再取得し、解決しなければ欠測として停止する。明らかなファイル形式不適合も記録する。低核数・小核・核小体なしを理由に視野や核を削除しない。
- 飽和、焦点、検出失敗、境界、多核、断片、融合・過分割は品質項目として記録する。判定不能な結果を勝手に除外して解析を続けない。追加規則が必要なら測定前に承認・版更新する。
- 既存 showcase の核数による `derivation_rule` と `fragment_review` は流用しない。
- 今回のデータは操作再現・回帰試験用。開発中に参照したデータを独立精度評価と呼ばない。
