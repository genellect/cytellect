# Public DAPI/NCL source manifest

This directory stores provenance for 4DNFI7FAWT6C, associated with Li et al., Sceptic (Genome Biology, 2025). The original TIFF is retrieved into an explicitly selected directory outside the checkout by scripts/public_nucleolar.py.

Read docs/public-nucleolar-validation.md for the adopted channel order, conflicting portal metadata, projection uncertainty, absence of GFP, data-use basis and actual validation scope. This manifest does not grant a new license to the source image.

Only attributed derived previews and measurements may be added to the public UI after validation. Never put user research data in this fixture directory.
