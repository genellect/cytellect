2. 確認は 1 行の状態にする。例：`領域 ✓` `欠測 2 / 151 核 ▸` `撮影条件 □`。欠測の表は折りたたみ、欠測のある行だけを出す。
3. デモでは、記録済みの条件は確認済みとして開く（記録が確認の結果である）。記録のない指標は選択肢に出さない。
4. 記述（検定なし）は確認を待たずに出し、確認は検定・保存・図の出力の前に求める案を、オーナーの判断にかける（要件 S-10 に関わる）。
5. 右列：宣言の文を `実験回 3 · 対応あり · 独立性 未確認` の 1 行にし、「実験」へのリンクにする（デモでは「実験を見る」）。自動計算の説明と「計算する条件」の行は消す（条件名は結果の見出しにある）。主要指標の印は、宣言があるときに主要指標にだけ付ける。

**P0：実験**

6. 見出しは体言止めにする（例：「2 群の比較：対照 × 処理」）。表より上の段落・流れ・青い帯を消す。
7. 意味は表に持たせる。列見出しを「実験回（n = 3）」にし、各行の右端に「差（処理 − 対照）」の列を置いて、同じ行の 2 つが対であることを線で示す。
8. まとめ方は、この実験の実数を入れた 1 行の図にする：`● 151 核 → ▢ 18 視野 → 3 実験回 → n = 3`。一般論の単語の列にしない。
9. 状態は「項目：値」の並びにする：`実験回 3` `群 2` `視野 18 / 18` `独立性 未確認 → 検定なし`。デモの断り書きは `公開データ（変更不可）` の 1 つにまとめ、理由は開いたときに出す。
10. 「主要指標」は、デモで宣言がなければ節ごと出さない。ワークスペースでは選択欄 1 行にし、段落を置かない。

**P1：指標の選択**

11. 「対象」を 3 つのボタン（核／核小体／核質）にし、選んだ区画を塗った小さな核の絵を添える。選択肢が常に見え、何を測るかが絵で分かる。
12. 観測の単位は、指標名の横のタグ（`核ごと` `核小体ごと`）にする。太字の文をやめ、定義は ⓘ で開く。
13. px²／µm²、原値／背景補正は、指標の下の切替にする。核小体の 20 項目が 9 項目前後になる。

**P1：画像**

14. 領域＝核小体の既定は「核小体ごと」に戻す（画像の輪郭と対応する）。
15. 核ごとのまとめは、列の順を核小体の列から始める（核小体数、総面積、面積割合、最大の割合、離心率）。または、画像で核を選ぶと、その核のまとめを 1 行で出す：`この核：核小体 3 個 · 32.0 µm² · 18.9% · 離心率 0.89`。
16. 次の一手を、見えている表の値に合わせる（Issue の A-2）。

**P2：結果の読みやすさ（main からある問題。別の Issue）**

17. 輝度の比較で、箇条書き（%）と表（絶対値）の単位をそろえる。回ごとに明るさが大きく違う指標は、グラフの軸や回ごとの正規化を検討する。原値の a.u. の比較を、ほかの指標と同じ「結論」として出してよいかは、生物学的な妥当性の観点でオーナーの判断が要る。
18. グラフを結果の領域の幅に合わせて大きくする。

**進め方**

19. この PR は Draft に戻すか閉じ、Issue の計画どおり (a) 統計の導線とラベル、(b) 実験、(c) 指標の選択と核小体の表に分ける。(a) は main の録画のままで確かめられる。
20. 画面の PR は、実装の前に、4 画面の案（図か簡単なモック）をオーナーに見せて合意する。PR には、変更前後の同じ条件のスクリーンショットを必ず付ける。
21. 受入に「最初の表示域で、ラベル以外の文は 1 文まで」のような、文章量の上限を入れる。
