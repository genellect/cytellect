# 群間比較の UX 改善：要件定義書（案）

作成：2026-10-25。改訂：2026-10-25（オーナーの回答を反映）。**独立レビュー前の案です。実装はまだ行いません。** 目的・決定事項・完了条件は [目標定義書](goals.md) にあります。ここでは、満たすべき要件を「何ができるべきか」で定め、画面の配置や API の形は決めません。未回答の質問に関わる要件には、その ID（Q2、Q8、Q9、Q10）を付けています。

## 1. 位置づけ

- この要件は、既存の[要件](../../requirements.md)の科学的な約束（原画像の画素値、共通実装による測定と統計、独立実験単位、明示的な比較の宣言）を変えません。変えるのは、最初の画面、入力、表示、指標、入力の上限、デモです。
- 既存の要件 U01（画像の追加の前に設定を出さない）と I07（入力の上限）は、オーナーの合意（2026-10-25）により見直します（[§7](#7-既存の要件との関係)）。
- 承認後は、内容を [要件](../../requirements.md)、[ワークスペースの再設計](../../workspace-redesign.md)、[公開デモ](../../showcase.md)、[計算仕様](../../methods.md)、[roadmap](../../roadmap.md) に移し、この下書きは削除します。

## 2. 用語

| 用語 | 意味 | 既存のデータとの対応 |
|---|---|---|
| 1 画面 | 1 つの群を記述する形。分布を示し、検定はしない | 記述統計（S09） |
| 2 画面 | 2 つの群を並べて比べる形。実験日を n として検定する | 群間比較（S10、S16） |
| 群 | 比べる実験条件（例：WT、薬剤処理）。1 つの画面が 1 つの群にあたる | `condition` |
| 実験日 | 独立に行った実験の 1 回。n の単位。同じ実験日の 2 群は対になる | `experimental_unit` と `pair`。日付は `acquisition_date` |
| 視野 | 1 か所を撮影した画像。複数の染色（チャンネル）を持つ | 視野（field）とチャンネル |
| 細胞 | 検出した核の 1 つ（細胞の輪郭の染色があれば、その輪郭を含む） | 領域（region） |

同じ実験日に独立した実験を 2 回行う場合に備え、実験日には日付とは別の名前を付けられるようにします（例：2026-10-01 a、2026-10-01 b）。

## 3. 指標の一覧

研究者の問いから指標を選べるようにします。すべての染色は同じ視野のチャンネルなので、細胞ごとに複数の染色の値を組み合わせられます。「現状」は 2026-10-25 時点の実装です。

| 問い | 指標 | 必要な染色 | まとめ方（細胞 → 視野 → 実験日） | 現状 | 段階 |
|---|---|---|---|---|---|
| 核が大きく・小さくなったか | 核の面積 | 核染色 | 中央値 → 平均 → 実験日 | あり | 第一 |
| 細胞が増えた・減ったか | 視野あたりの細胞数（校正があれば mm² あたり） | 核染色 | 視野ごとの数 → 視野の平均 → 実験日 | なし（領域数を一覧に表示するだけ） | 第一 |
| 陽性細胞が増えた・減ったか | 陽性細胞の割合、視野あたりの陽性細胞数 | 核染色 ＋ 判定する染色（GFP など） | 視野ごとの割合 → 視野の平均 → 実験日 | 核の GFP 判定は NCL/GFP の専用レシピだけ | 第一 |
| 核小体が大きく・少なくなったか | 核あたりの核小体の数・総面積・面積割合 | 核染色 ＋ 核小体の染色（NCL、NPM1、FBL など） | 中央値 → 平均 → 実験日 | 数と面積割合はあり。総面積は確認が必要 | 第一 |
| 核内の量が変わったか | 核の平均・積算輝度（背景補正の有無） | 核染色 ＋ 測る染色 | 中央値 → 平均 → 実験日 | あり | 第一 |
| 核小体から核質へ移ったか | 核質／核小体の輝度比（log2） | 核染色 ＋ NCL | 中央値 → 平均 → 実験日 | あり | 第一 |
| 細胞・細胞質が大きく・小さくなったか | 細胞の面積、細胞質の面積（細胞 − 核） | 核染色 ＋ 細胞の輪郭の染色（CellMask、phalloidin など） | 中央値 → 平均 → 実験日 | 細胞の輪郭（細胞 ROI）は一部あり。細胞質の自動検出はない | 第二 |
| 核と細胞質のどちらにあるか | 核／細胞質の輝度比 | 核染色 ＋ 輪郭の染色 ＋ 測る染色 | 中央値 → 平均 → 実験日 | なし | 第二 |
| 2 つの量が連動するか | 相関 | 上記の 2 つ | 実験日ごと | あり | 既存 |

**M-01** 指標は、上の「問い」の言葉で選べる。指標の正式名・定義・単位・まとめ方は、選んだ後に確かめられる。

**M-02** 必要な染色や校正が登録されていない指標は選べず、何が足りないかを示す。別の染色を代わりに使って計算しない。

**M-03** 細胞数は、視野の選び方と、はがれた細胞の扱いに影響される。視野を結果を見ずに選んだか、端にかかる細胞をどう扱ったかを記録し、Methods に書く。細胞数は、画像に写った（付着している）細胞の数であり、生存率や増殖率そのものではないことを、指標の説明に示す。

**M-04** 陽性の判定は、陰性対照から決めたしきい値か、明示したしきい値による。陰性対照のない判定は探索的と表示する（既存の S01 と同じ）。判定の基準は群・実験日をまたいで同じものを使い、群ごとに決め直さない。

**M-05** 指標を陽性細胞に限って比べられる（例：GFP 陽性細胞の核の面積）。限った条件と、限る前後の細胞数を結果に残す。

**M-06** 新しい指標は、測定の版を更新し、[計算仕様](../../methods.md)と数値テストを同じ変更で追加する。

## 4. 機能要件

### 4.1 最初の選択と入力（G1）

**E-01** 最初の画面で「1 画面（1 群を記述する）」か「2 画面（2 群を比べる）」を選ぶ。選ぶ前に、それぞれで何ができるかが短い説明で分かる。

**E-02** 画面ごとに、群の名前（例：WT、薬剤処理）を付ける。2 画面では、どちらを対照にするかを選ぶ。

**E-03** 実験日の一覧は 2 つの画面で共通にする。画面ごと・実験日ごとに、視野の画像をまとめて追加する。各群・各実験日の視野数が一覧で分かる。

**E-04** 1 つの視野の複数のチャンネル（DAPI、GFP、NCL、CellMask など）は、現在の自動の組み分け（OME のメタデータ、ファイル名、フォルダ）で視野にまとめ、研究者が確かめて決める。ファイル名やフォルダから、群・実験日・染色を推定して確定しない（既存の U02、I11 と同じ）。

**E-05** 欠けている組み合わせ（ある実験日に、ある群の画像がない、など）が、統計に進む前に分かる。

**E-06** 1 画面で始めた作業を、入力した画像と結果を保ったまま 2 画面に広げられる。

**E-07** 既存の視野ごとの実験情報の表は、詳細の確認と修正のために残す。E-01–E-06 で入れた内容と、同じ記録を表示・編集する。

### 4.2 群の並置表示（G2）

**V-01** 2 画面では、2 つの群の視野を左右（狭い画面では上下）に並べ、同じチャンネル・同じ拡大率・同じ位置を同時に表示する。

**V-02** 実験日を選ぶと、2 つの画面に同じ実験日の視野が出る。各画面の中で、その実験日の視野を切り替えられる。

**V-03** 並べた画像は同じ表示範囲（明るさの対応）で描き、そのことと範囲の値を画面に示す。視野ごとの自動調整のままでは並べない（既存の A13 の延長）。

**V-04** 並べた状態で、検出した輪郭、測定値、除外の状態を確認・修正できる。修正は既存の規則どおり、依存する測定・統計・図だけを無効にする。

### 4.3 対象の除外と品質（G4、G6）

**Q-01** 細胞・視野の除外の規則（大きさ、画像の端、飽和、断片など）は、測定の前に決め、両群に同じく適用する。群ごとや結果を見てから決め直さない。

**Q-02** 除外した細胞・視野の数を、群・実験日ごとに結果に示す。除外の有無で結論が変わるかを、除外しない場合の結果と並べて確かめられる。

**Q-03** 核の大きさを比べるときは、大きさで決まる除外（小さな物体を断片として削除するなど）が、結果そのものを左右することを示す。核の縮小や断片化が起きる処理（アポトーシスなど）では、断片を 1 つの核として数えるか、除外するかを測定の前に決め、その影響を Q-02 の方法で示す。

**Q-04** 既存の品質の警告（飽和、検出の失敗、核小体を確定できない核）は、統計を止める理由と、止めない理由を区別して示す。止める場合は、何をすれば進めるかを示す。

### 4.4 結果の表示（G4）

**S-01** 結果の先頭に、保存した統計の値から作った一文を出す。例：「核の面積は、DMSO に比べ 〈処理〉 で 〈差〉 µm²（〈%〉、95% 信頼区間 〈下限〉–〈上限〉）。実験日 n = 3、対応のある t 検定 p = 〈値〉」。

**S-02** 同じ場所に、各実験日の変化の向きを示す（例：3 日中 3 日で縮小）。

**S-03** n が何か（実験日・視野・細胞のそれぞれの数）を区別して示す。細胞数・視野数を n と表示しない。

**S-04** 差の大きさは、差と、対照に対する割合（%）で示す。対照の平均が 0 に近い場合や負の値がある場合は割合を表示せず、理由を出す。

**S-05** 既存の注意（n が 5 未満、飽和、欠測、除外）は、結果の文のすぐ近くに平易な言葉で出す。内部の列名や警告のコードを画面の見出しにしない（元データの CSV には残す）。

**S-06** 結果の文と表の数値は、ブラウザで計算し直さず、API が保存した値を表示する。

### 4.5 統計（G4、G5）

**T-01** 2 画面の既定は、実験日を対にした対応のある比較（対応のある t 検定、または Wilcoxon 符号付き順位検定）とする。ある実験日に片方の群がない場合は、その日を対から外さずに統計を止め、理由を示す（既存の S10 と同じ）。

**T-02** 既存の検定を使う。手法は、観察した p 値や正規性の検定で選ばない。順位に基づく検定は、n が小さいと有意になりえないことを、選ぶ前に示す（例：対が 3 つの Wilcoxon 符号付き順位検定の両側 p は 0.25 未満にならない）。

**T-03** 3 群以上の比較と、3 群以上の対応のある比較（Friedman など）、混合効果モデルは、この変更の範囲外とする。（Q2）

**T-04** 割合の指標（陽性細胞の割合）は、視野ごとの割合を実験日でまとめてから比べる。細胞を n とする割合の検定（カイ二乗検定など）は行わない。

**T-05** 1 画面では検定を行わず、実験日ごとの分布と要約（中央値、四分位、細胞数・視野数）を示す。

### 4.6 図（G5）

**F-01** 2 画面の既定の図は SuperPlot 形式とし、細胞（薄い点）、実験日の平均（濃い点、日ごとに同じ記号）、群の平均と 95% 信頼区間、同じ実験日を結ぶ線を描く。

**F-02** 選べる形に、実験日の平均の棒と各日の点（SD または 95% 信頼区間）を加える。細胞を n とする棒グラフは作らない。（Q9）

**F-03** 図の凡例と元データ CSV に、点が何を表すか（細胞・視野・実験日）と n を書く。

**F-04** 図の点を選ぶと、その実験日・視野・細胞の元画像を開ける（既存の S11、S12 の延長）。

**F-05** 代表画像のパネル（2 群の画像を並べ、スケールバーを付けたもの）は第二段階とする。

### 4.7 公開デモ（G6）

**X-01** `/demo` を開くと、追加の操作なしに、核の縮小を示す場面の 2 画面の並置、結果の一文、図が表示される。

**X-02** デモには、核の縮小、細胞数の変化、核小体の変化の 3 つの場面を用意し、切り替えて確かめられる。1 つの公開データで 3 つをそろえられない場合は、場面ごとに別のデータを使い、どの場面がどのデータかを示す。

**X-03** 各場面が示す変化は、そのデータの出典の論文が報告している変化とする。結果の文の近くに、出典の報告（論文の主張）と、デモでの測定（このデータでの値）を分けて示す。報告のない変化を、別の変化の代わりに見せない。（Q10）

**X-04** 各場面の視野と除外の規則は測定の前に決め、規則と選んだ視野を記録する（現在の [manifest.json](../../../apps/web/public/showcase/manifest.json) の `derivation_rule` と同じ方式）。結果を見てから視野を入れ替えない。

**X-05** 訪問者は、記録した範囲で指標と実験日を切り替えられる。記録にない操作は、既存の方式どおり、エラーではなく案内を出す。

**X-06** デモの数値は公開画像による例示であり、研究室の画像での妥当性を示さないことを、既存のデモの表示と同じ場所に示す。

## 5. 非機能要件

| N-01 | 測定値・統計・結果の文の数値は、API と解析パッケージの共通実装だけが作る。デモのブラウザ内の値は、同じ操作のサーバー出力と照合する（既存の[公開デモ](../../showcase.md)の検証） |

## 6. 公開データ

### 6.1 選定の基準

デモと検証に使う公開画像一式は、次をすべて満たすものを選びます。

| ID | 基準 |
|---|---|
| D-01 | 論文として発表され、データの DOI または恒久的な URL がある |
| D-02 | 再配布と改変（切り出し）ができるライセンス（CC0、CC BY）。ライセンスの原文を確認し、記録する |
| D-03 | 同じ実験（同じ細胞株、同じ撮影条件、同じプレートまたは同じ日）の中に、対照と処理がある |
| D-04 | 実験日（プレート、日、反復）が識別でき、できれば 3 回以上ある。独立性が出典に書かれていない場合は、その事実をデモに示す |
| D-05 | 示す変化（核の縮小、細胞数の変化、核小体の変化）が、出典の論文で報告されている（向きと、できれば大きさ） |
| D-06 | 核染色を含み、1 視野ごとにチャンネルがそろう。核小体・細胞の輪郭・陽性判定の染色があれば、より多くの指標を示せる |
| D-07 | 画素の大きさ（µm/px）、ビット深度、撮影条件が分かる。測定に十分な解像度がある（核小体には 40 倍以上が望ましい） |
| D-08 | 各群・各実験日に 3 視野以上あり、デモの容量（N-03）に収まるよう切り出せる |

### 6.3 次に行う確認

1. 核の縮小を定量して報告している論文と、その元画像の公開先・ライセンスを探す。
2. Cell Painting Gallery の cpg0016 の陽性対照の名前と、論文で報告された表現型を、メタデータと JUMP の論文で確かめる。
3. Schmidt ら 2022 の方法の節で、濃度・処理時間・チャンネル・反復の定義を確かめ、デモの表記（現在の「ActD 1 µM」を含む）を出典どおりに直す。
4. 選んだデータで、測定の前に視野の選び方と除外の規則を決めて記録し（X-04、Q-01）、fixture として登録する（既存の `fixtures/public` の方式）。
