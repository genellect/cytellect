# 群間比較の UX 改善：要件定義書（案）

作成：2026-10-25。**オーナー承認前の案です。** 目的と完了条件は [目標定義書](goals.md) にあります。ここでは、満たすべき要件を「何ができるべきか」で定め、画面の配置や API の形は決めません。[目標定義書 §7](goals.md#7-判断が必要な事項) の回答によって変わる要件には、関係する質問の ID を付けています。

## 1. 位置づけ

- この要件は、既存の[要件](../../requirements.md)の科学的な約束（原画像の画素値、共通実装による測定と統計、独立実験単位、明示的な比較の宣言）を変えません。変えるのは入力・表示・指標・デモです。
- 承認後は、内容を [要件](../../requirements.md)、[ワークスペースの再設計](../../workspace-redesign.md)、[公開デモ](../../showcase.md)、[roadmap](../../roadmap.md) に移し、この下書きは削除します。

## 2. 用語

| 用語 | 意味 | 既存のデータとの対応 |
|---|---|---|
| 群 | 比べる実験条件（例：WT、薬剤処理） | `condition` |
| 実験回 | 独立に行った実験の 1 回（例：2026-10-01 の実験）。n の単位 | `experimental_unit`。実験日は `acquisition_date`、同じ回の群どうしの対は `pair` |
| 染色セット | 同じ組み合わせで染めて撮影した視野の集まり（例：DAPI ＋ GFP） | 視野ごとのチャンネルの組み合わせ（新しい区分。Q4） |
| 視野 | 1 回の撮影の画像（1 つ以上のチャンネル） | 視野（field） |
| 細胞 | 検出した核（と、あれば細胞の輪郭）の 1 つ | 領域（region） |
| 1 群の記述 | 1 つの群の分布を示す。検定はしない | 記述統計（S09） |
| 2 群の比較 | 2 つの群を、実験回を n として比べる | 群間比較（S10、S16） |

## 3. 指標の一覧

研究者の問いから指標を選べるようにします。「現状」は 2026-10-25 時点の実装です。

| 問い | 指標 | 必要な染色 | まとめ方（細胞 → 視野 → 実験回） | 現状 | 段階 |
|---|---|---|---|---|---|
| 細胞が増えた・減ったか | 視野あたりの細胞数（校正があれば mm² あたり） | 核染色 | 視野ごとの数 → 視野の平均 → 実験回 | なし（領域数は一覧に表示するだけ） | 第一 |
| 陽性細胞が増えた・減ったか | 陽性細胞の割合、陽性細胞数 | 核染色 ＋ 判定する染色（GFP など） | 視野ごとの割合 → 視野の平均 → 実験回 | 核の GFP 判定は NCL/GFP の専用レシピだけ | 第一 |
| 核が大きく・小さくなったか | 核の面積 | 核染色 | 中央値 → 平均 → 実験回 | あり | 第一 |
| 核内の量が変わったか | 核の平均・積算輝度（背景補正の有無） | 核染色 ＋ 測る染色 | 中央値 → 平均 → 実験回 | あり | 第一 |
| 核小体が大きく・少なくなったか | 核あたりの核小体の数・総面積・面積割合 | 核染色 ＋ 核小体の染色（NCL、NPM1、FBL など） | 中央値 → 平均 → 実験回 | 数と面積割合はあり。総面積は確認が必要 | 第一 |
| 核小体から核質へ移ったか | 核質／核小体の輝度比（log2） | 核染色 ＋ NCL | 中央値 → 平均 → 実験回 | あり | 第一 |
| 細胞・細胞質が大きく・小さくなったか | 細胞の面積、細胞質の面積（細胞 − 核） | 核染色 ＋ 細胞の輪郭の染色（CellMask、phalloidin など） | 中央値 → 平均 → 実験回 | 細胞の輪郭（細胞 ROI）は一部。細胞質の自動検出はない | 第二 |
| 核と細胞質のどちらにあるか | 核／細胞質の輝度比 | 核染色 ＋ 輪郭の染色 ＋ 測る染色 | 中央値 → 平均 → 実験回 | なし | 第二 |
| 2 つの量が連動するか | 相関 | 上記の 2 つ | 実験回ごと | あり | 既存 |

**M-01** 指標は、上の「問い」の言葉で選べる。指標の正式名・定義・単位・まとめ方は、選んだ後に確かめられる。

**M-02** 必要な染色や校正が登録されていない指標は選べず、何が足りないかを示す。別の染色を代わりに使って計算しない。

**M-03** 視野あたりの細胞数は、視野の選び方に影響されるため、画面と Methods に「視野は撮影時に結果を見ずに選んだか」を確認する欄を設ける。画像の端にかかる細胞の扱いを記録する。

**M-04** 陽性の判定は、陰性対照から決めたしきい値、または明示したしきい値による。陰性対照がない判定は探索的と表示する（既存の S01 と同じ）。判定の基準は群・実験回をまたいで同じものを使い、群ごとに決め直さない。

**M-05** 新しい指標は、測定の版を更新し、[計算仕様](../../methods.md) と数値テストを同じ変更で追加する。

## 4. 機能要件

### 4.1 実験の構造の入力（G1）

**E-01** 画像を追加する流れの中で、「1 群の記述」か「2 群の比較」かと、群の名前を選べる。後から変えられる。（Q1、Q5）

**E-02** 実験回を、実験日と名前で登録できる。同じ実験回の群どうしは自動で対になり、各群・各回の視野数が一覧で分かる。（Q3）

**E-03** 群・実験回・染色セットへの画像の割り当ては、フォルダ・ファイル名の候補を示したうえで、研究者が確かめて決める。ファイル名やフォルダの数から、群・実験回・染色を推定して確定しない（既存の U02、I11 と同じ）。

**E-04** 群の中に染色セットを複数登録できる。染色セットごとに、使える指標が決まる（例：DAPI ＋ GFP のセットでは陽性細胞の割合）。（Q4）

**E-05** 欠けている組み合わせ（ある回にある群の画像がない、など）が、統計に進む前に分かる。

**E-06** 既存の視野ごとの実験情報の表は、詳細の確認と修正のために残す。E-01–E-05 で入れた内容と同じ記録を表示・編集する。

### 4.2 群の並置表示（G2）

**V-01** 2 群の比較では、2 つの群の視野を左右（狭い画面では上下）に並べ、同じチャンネル・同じ拡大率・同じ位置を同時に表示する。

**V-02** 並べた画像は同じ表示範囲（明るさの対応）で描き、そのことと範囲の値を画面に示す。視野ごとの自動調整のままでは並べない（既存の A13 の延長）。

**V-03** 並べた状態で、検出した輪郭、測定値、除外の状態を確認・修正できる。修正は既存の規則どおり、依存する測定・統計・図だけを無効にする。

**V-04** 各群の中で、実験回と染色セットを切り替えられる。

### 4.3 結果の表示（G4）

**S-01** 結果の先頭に、保存した統計の値から作った一文を出す。例：「核小体の総面積は、未処理に比べ ActD 処理で 〈差〉 µm²（〈%〉、95% 信頼区間 〈下限〉–〈上限〉）。独立した実験 n = 3、対応のある t 検定 p = 〈値〉」。

**S-02** 同じ場所に、各実験回の変化の向き（例：3 回中 3 回で減少）を示す。

**S-03** n が何か（実験回、視野、細胞のそれぞれの数）を区別して示す。細胞数・視野数を n と表示しない。

**S-04** 差の大きさは、差と、対照に対する割合（%）で示す。割合は対照の平均が 0 に近い場合や負の値がある場合に定義できないので、その場合は表示しない理由を出す。

**S-05** 既存の注意（n が 5 未満、飽和、欠測、除外）は、結果の文のすぐ近くに平易な言葉で出す。内部の列名や警告のコードを画面の見出しにしない（元データの CSV には残す）。

**S-06** 結果の文と表の数値は、ブラウザで計算し直さず、API が保存した値を表示する。

### 4.4 統計（G4、G5）

**T-01** 2 群の比較の既定は、実験回ごとに対になっていれば対応のある比較、そうでなければ独立した比較とする。どちらを使ったかを結果の文に入れる。

**T-02** 既存の検定（Welch・対応のある t、Mann–Whitney U、Wilcoxon、3 群以上の Welch ANOVA・Kruskal–Wallis と Holm）を使う。手法は観察した p 値や正規性の検定で選ばない。

**T-03** 3 群以上の対応のある比較（Friedman など）と混合効果モデルは、この変更の範囲外とし、選べないことと理由を示す。（Q2）

**T-04** 割合の指標（陽性細胞の割合）は、視野ごとの割合を実験回でまとめてから比べる。細胞を n とする割合の検定（カイ二乗検定など）は行わない。

### 4.5 図（G5）

**F-01** 群間比較の既定の図は SuperPlot 形式とし、細胞（薄い点）、実験回の平均（濃い点、回ごとに同じ記号）、群の平均と 95% 信頼区間を描く。

**F-02** 選べる形に、実験回の平均の棒と各回の点（SD または 95% 信頼区間）、対応線を加える。細胞を n とする棒グラフは作らない。（Q9）

**F-03** 図の凡例と元データ CSV に、点が何を表すか（細胞・視野・実験回）と n を書く。

**F-04** 図の点を選ぶと、その実験回・視野・細胞の元画像を開ける（既存の S11、S12 の延長）。

**F-05** 代表画像のパネル（2 群の画像を並べ、スケールバーを付けたもの）は第二段階とする。

### 4.6 公開デモ（G6）

**X-01** `/demo` を開くと、追加の操作なしに、2 群の並置、結果の一文、図が表示される。

**X-02** デモが示す変化は、出典の論文が報告している変化とする。結果の文の近くに、出典の報告（論文の主張）と、デモでの測定（このデータでの値）を分けて示す。

**X-03** デモの視野は、測定の前に決めた規則で選び、規則と選んだ視野を記録する（現在の [manifest.json](../../../apps/web/public/showcase/manifest.json) の `derivation_rule` と同じ方式）。結果を見てから視野を入れ替えない。

**X-04** 訪問者は、記録した範囲で指標を切り替えられる（例：核の面積、細胞数、核小体の面積）。記録にない操作は、既存の方式どおりエラーではなく案内を出す。

**X-05** デモの数値は、公開画像による例示であり、研究室の画像での妥当性を示さないことを、既存のデモ表示と同じ場所に示す。

## 5. 非機能要件

| ID | 要件 |
|---|---|
| N-01 | 測定値・統計・結果の文の数値は、API と解析パッケージの共通実装だけが作る。デモのブラウザ内の値は、同じ操作のサーバー出力と照合する（既存の [公開デモ](../../showcase.md) の検証） |
| N-02 | 入力の上限を、2 群 × 実験回 3 × 染色セット 4 × 各 5 視野（120 視野）が入るように見直す。見直す前に、ローカル版でのメモリと時間を測る（Q6） |
| N-03 | デモの配信量と、訪問者の端末での初回表示の時間を、現在（記録の再生、seed 約 40 MB）より悪化させない。視野を増やす場合は、切り出しの大きさを下げて調整する（Q8） |
| N-04 | 並置表示と結果の文は、キーボードで操作でき、色だけで群を区別しない（色覚に配慮した配色と記号の併用） |
| N-05 | 公開サイトは研究画像を受け付けない（既存の方針のまま） |
| N-06 | 画面の言葉は操作名と短い説明にする。初心者向けの説明は、判断が必要な場所にだけ置き、詳細は開いて読めるようにする |

## 6. 公開データ

### 6.1 選定の基準

デモと検証に使う公開画像一式は、次をすべて満たすものを選びます。

| ID | 基準 |
|---|---|
| D-01 | 論文として発表され、データの DOI または恒久的な URL がある |
| D-02 | 再配布と改変（切り出し）ができるライセンス（CC0、CC BY）。ライセンスの原文を確認し、記録する |
| D-03 | 同じ実験（同じ細胞株、同じ撮影条件、同じプレートまたは日）の中に、対照と処理がある |
| D-04 | 実験回（プレート、日、反復）が識別でき、できれば 3 回以上ある。独立性が出典に書かれていない場合は、その事実をデモに示す |
| D-05 | 処理による変化が、出典の論文で報告されている（向きと、できれば大きさ） |
| D-06 | 核染色を含み、1 視野ごとにチャンネルがそろう。核小体・細胞の輪郭・陽性判定の染色があれば、より多くの指標を示せる |
| D-07 | 画素の大きさ（µm/px）、ビット深度、撮影条件が分かる。測定に十分な解像度がある（核小体には 40 倍以上が望ましい） |
| D-08 | 各群・各回に 3 視野以上あり、デモの容量（N-03）に収まるよう切り出せる |

### 6.3 次に行う確認

1. Cell Painting Gallery の cpg0016 の陽性対照 8 種の名前と、論文で報告された表現型を、メタデータと JUMP の論文で確かめる。核の大きさ・細胞数・細胞の大きさが明確に変わる化合物があれば、2 群のデモの第一候補にする。
2. Schmidt ら 2022 の方法の節で、濃度・処理時間・チャンネル・反復の定義を確かめ、デモの表記（現在の「ActD 1 µM」を含む）を出典どおりに直す。
3. 選んだデータで、測定の前に視野の選び方を決めて記録し（X-03）、fixture として登録する（既存の `fixtures/public` の方式）。
4. どの候補でも、論文が報告していない変化を、デモの主張にしない。

## 7. 既存の要件との関係

| 既存の要件 | 関係 | 対応 |
|---|---|---|
| U01：画像の追加の前に設定やフォームを出さない | E-01 と衝突しうる | 画像の追加を最初の操作のまま残し、その中で群を選ぶ案（Q5） |
| I07：100 視野、3 チャンネル | 想定する実験の規模が超える | N-02 で見直す（Q6） |
