## Delivered behavior

NCL refinement uses model-anchored signal support within an adopted parent
nucleus. Raw model candidates, binding/rejection evidence, lineage and final
candidate labels retain their separate meanings. StarDist nuclei, original
measurement pixels, saved historical recipes and adopted/manual masks are not
silently replaced. Researcher adoption remains a separate operation.

The current AI contract supports protocol 4.3.0 and returns to the same analysis
settings/results. Image addition, navigation and mask editing do not call the
paid service. Its existing monthly USD 5 cap is unchanged.

File and folder controls remain disabled until the workspace has initialized,
preventing intake from being discarded during the initial exclusive load.

## Installation boundary

The ordinary archive contains Cellpose adapter assets, fixed manifests and
explicit provisioning scripts; it does not contain the model weights or install
Torch into the ordinary Python 3.14 environment. After ordinary setup, follow
the optional signed Python 3.12 procedure in
[the adapter instructions](../engines/cellpose/README.md#windows-optional-installation).
Provisioning downloads the pinned model/packages. Image jobs use verified local
assets without runtime downloads.

The ordinary release suite does not exercise this optional runtime. Its exact
installed-package validation and operating-system acceptance are separate gates.
No OS application-control policy may be weakened to pass them.

The first task-private PC installation stopped during Python archive extraction,
before executing Python. An atomic temporary member name exceeded the Windows
PowerShell 5.1 path limit (264 characters; the parent directory existed), causing
`DirectoryNotFoundException` (`0x80070003`). The four pinned PSF launchers matched
their hashes and had valid signatures. This is retained as a harness-location
failure, not an AppControl rejection or a passed installation. The same immutable
archive was checked in a short dedicated location without changing OS
policy, the product scripts or private evidence references. Python extraction
then passed; the owner requested a pause during `install_dependencies`, before
ordinary setup completed. Its task-owned process
and children were stopped, and cached downloads/partial installation were
preserved. Optional provisioning, installed identity/inference, repeat reuse
and launcher acceptance had not started at the pause. They were not counted as
passes.

### Resumed PC verification, 2026-10-10

The exact short-location ordinary setup resumed and completed successfully,
including its storage result with a readable process inventory and one retained
installation. The fixed Cellpose model and package provisioning completed, but
the optional script's final import check failed. An isolated import reproduced
the failure, and Windows Code Integrity event 3077 identified
`fill_voids.cp312-win_amd64.pyd`. This is an actual application-control rejection,
separate from the earlier long-path extraction failure.

The optional configuration was not committed by the setup script. Installed
Cellpose identity, private real-image inference, repeat reuse and optional
launcher checks remain unexecuted. No protection policy, file-origin flag,
signature trust or exclusion was changed to make the dependency execute. The
immutable archive/tag was not modified and is not published as a validated
optional Windows runtime.

Docker scientific execution remains available with the accepted protocol. Native
Windows compatibility requires separately versioned source and a new immutable
package, followed by the same real-image/full-region and installed gates; it
must not be introduced by silently modifying this draft ZIP.

## Evidence limits

The ordinary workflow uses registered public microscopy for Fiji integration
and existing deterministic numerical fixtures for arithmetic/transport. Those
fixtures are not NCL biological acceptance. NCL acceptance uses only the supplied
private real images and the researcher-reviewed partition outside Git/CI.

Reproducing that partition and original-pixel measurements does not establish
general sensitivity, ground-truth accuracy on unseen specimens, or independent
researcher usability. Private inputs, paths, images, labels, values and browser
captures are not part of this release.
