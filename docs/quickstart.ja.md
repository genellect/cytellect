# Cytellect はじめての画像解析

このガイドは、計画の引継ぎ・一括登録に対応した **Windows版 0.1.0-local.11（開発プレビュー）** 向けです。[配布版とリリース情報](https://github.com/genellect/cytellect/releases/tag/v0.1.0-local.11)

公開画像で、核の中の蛍光を測り、元画像までたどれる図を作ります。

## 用意するもの

Windows PCと、練習用のチャンネル別TIFF画像を用意します。初回セットアップにはインターネット接続が必要です。例には、公開データ **BBBC013** のA01・A06・A12を使います。

練習画像：[Cytellect-BBBC013-practice-v1.zip](https://github.com/genellect/cytellect/releases/download/v0.1.0-local.11/Cytellect-BBBC013-practice-v1.zip)。インストーラーとは別の任意ダウンロードです。展開すると、同名フォルダーに6枚のTIFFと出典説明が入ります。

| 画像 | 実際の染色・標識 | 今回の用途 |
|---|---|---|
| `A01-dapi.tif` などの `-dapi.tif` | DRAQ | 核の位置を検出する |
| `A01-gfp.tif` などの `-gfp.tif` | FKHR-EGFP | 核内の蛍光強度を測る |

元データはヒトU2OS細胞の公開顕微鏡画像です。DRAQはDAPIではありません。練習用TIFFは公開8-bit BMPの画素値を変えずに形式変換したもので、装置の元形式の定量性を検証した画像ではありません。[画像の出典：BBBC013](https://bbbc.broadinstitute.org/BBBC013)

## 1．測ることを決める

[Windows版ZIP](https://github.com/genellect/cytellect/releases/download/v0.1.0-local.11/Cytellect-0.1.0-local.11-windows-x64.zip)を展開し、**Cytellect Setup.cmd** で初回セットアップを行います。その後はCytellectのショートカットから開き、**「解析を開始」** へ進みます。通常の起動にコマンド入力は不要です。

新しい作業の「計画ガイドを開く」から、次のように選びます。

| 項目 | この例で選ぶ内容 |
|---|---|
| 測りたい量／測定する領域 | 領域内の平均輝度／核 |
| 領域の決め方／測定する蛍光チャンネル | 核染色から核を検出する／GFP |
| 測定に使う画像 | 2DグレースケールTIFF / OME-TIFF |
| 核染色チャンネル | ある（この例はDRAQ） |
| まず確認したいこと | 測定値と分布を確認したい |
| GFPによる陽性選別 | 行わない |

背景と撮影条件は画像・記録に合わせて答え、不明な項目は未確認にします。候補の **「核染色からの核検出・測定」** を選んで「この計画で作業を作成」へ進み、作業名を入力して作成します。

公開サイトで先に計画した場合は、計画メモを保存してWindows版で読み込みます。計画は、実画像の確認を済ませるものではありません。

## 2．画像とチャンネルを対応させる

まず「画像を登録」でA01の2枚を登録します。「チャンネルを追加」で2つにし、`A01-dapi.tif` の表示名・染色を **DRAQ**、`A01-gfp.tif` を **FKHR-EGFP** にします。各画像と表示名の対応を確認してから「この視野を登録」へ進みます。分からない画素サイズや実験情報は空欄にします。

「計画と実画像の対応」では、測る値に **FKHR-EGFPの平均（背景補正）** を選びます。ファイル名だけで染色を決めないでください。

背景補正平均は、核内の画素の平均から、そのチャンネルで選んだ背景ROIの中央値を引いた値です。補正後の負の値も保持します。

## 3．1視野で試し、領域を確認する

核の検出にDRAQを選び、核染色であることを確認します。画像上部でチャンネルを切り替え、それぞれ「背景」を選びます。細胞や測定領域と重ならない場所を3点以上の多角形で囲み、「背景を確定」してください。両チャンネルを確認したら **「この視野で検出を試す」** から始めます。適切な背景を選べない場合は、撮影条件や測定方法を見直します。

輪郭を画像と重ねて確認します。必要な領域を追加・修正し、対象外の領域は削除するか、理由を記録して除外します。保存後の測定値を確認してください。核の輪郭は細胞全体の輪郭とは異なります。

## 4．残りの視野へ進む

「複数視野をまとめて登録」で、残りのA06・A12だけを選びます。

| チャンネル | 選ぶ2ファイル | 取り除く末尾文字 |
|---|---|---|
| DRAQ | `A06-dapi.tif`、`A12-dapi.tif` | `-dapi` |
| FKHR-EGFP | `A06-gfp.tif`、`A12-gfp.tif` | `-gfp` |

対応表でA06とA12の2行に各チャンネルが揃うことを確認し、画像対応と実験情報を確認して登録します。未登録行が残った場合は再試行できます。成功後は **「登録した画像を確認」** で画像へ戻れます。

残りの視野でも背景を確認し、**「領域を保持して全視野を測定」** へ進みます。同じ検出条件なら、先ほど修正した領域を保持できます。条件を変えて再検出するときは、対象範囲と修正領域の扱いを確認してください。

## 5．測定値の分布を図にする

全視野の領域・背景・採否を確認します。「未反映の変更」が出たら **「背景・除外を反映して再測定」** を実行し、完了後に品質確認を完了します。**「分布と図」** でチャンネルと指標を確かめ、図を作成します。独立した反復実験か不明でも、測定値の分布は確認できます。

図の各点は1核の測定値、四角はその視野内の中央値です。独立実験の平均や信頼区間を示すものではありません。

この練習では、A01・A06・A12を独立した生物学的反復とは仮定せず、群間の有意差を調べません。細胞数や視野数は独立反復数の代わりになりません。

## 6．図と根拠を一緒に保存する

SVGまたはPDFと **「図の元データ」** を保存します。全チャンネルの測定CSVは、次の解析パッケージに含まれます。結果画面から元画像へ戻り、視野・領域ID・測定値の対応を確認できます。

**「保存と履歴」** から解析パッケージも保存してください。領域、測定値、条件、Methodsなどがまとまります。原画像は既定では含まれないため、別途保管するか、含める設定を明示して選びます。整った図が出力できても、領域定義や実験デザインの妥当性は研究者による確認が必要です。

## 保存期限と終了

画像と解析結果はPC内のCytellect専用フォルダーに保存され、**最後の明示的な操作から24時間** が保存期限です。画面を開いたままにするだけでは延長されません。必要な成果物は期限前に保存してください。

アプリ終了中に期限を迎えたデータは、次回起動時に削除します。終了時はブラウザのタブだけでなく、Cytellectの起動ウィンドウを閉じてください。

画像解析はローカル版で実行します。公開サイトは計画や解析例を確認する入口です。私有画像をクラウド上で処理する提供形態は、今後の対応です。
