# Cytellect はじめての画像解析

公開画像を使い、核の中の蛍光を測って、元画像までたどれる図を作る練習手順。

| 項目 | 内容 |
|---|---|
| 対象 | Cytellect の操作を覚える研究者 |
| 前提 | Windows 版を[インストールと更新の手順](install-windows.ja.md)でセットアップ済み、または [Docker Desktop 版](docker-desktop.md)を起動済み |
| 使う画面 | 詳細画面。起動中に Windows 版は `http://127.0.0.1:8765/legacy`、Docker 版は `http://127.0.0.1:3087/legacy` を開く。標準の作業画面向けの手順は改訂中 |
| 使う画像 | 公開データ BBBC013 の A01・A06・A12（練習用のチャンネル別 TIFF） |

配布版は常に [Cytellect のサイト](https://cytellect.vercel.app/)の最新版を使う。0.1.0-local.11 などの古い版は使わない。

## 1. 準備する

練習画像 [Cytellect-BBBC013-practice-v1.zip](https://github.com/genellect/cytellect/releases/download/v0.1.0-local.11/Cytellect-BBBC013-practice-v1.zip) をダウンロードして展開する。インストーラーとは別の任意ダウンロードで、展開すると同名フォルダーに 6 枚の TIFF と出典説明が入る。照合情報は[画像の出典](#画像の出典)にある。

| 画像 | 実際の染色・標識 | 今回の用途 |
|---|---|---|
| `A01-dapi.tif` などの `-dapi.tif` | DRAQ | 核の位置を検出する |
| `A01-gfp.tif` などの `-gfp.tif` | FKHR-EGFP | 核内の蛍光強度を測る |

元データはヒト U2OS 細胞の公開顕微鏡画像。DRAQ は DAPI ではない。練習用 TIFF は公開 8-bit BMP の画素値を変えずに形式変換したもので、装置の元形式の定量性を検証した画像ではない。

## 2. 測ることを決める

Cytellect を起動し、詳細画面を開いて **「解析を開始」** へ進む。通常の起動にコマンド入力は不要。

新しい作業の「計画ガイドを開く」から、次のように選ぶ。

| 項目 | この例で選ぶ内容 |
|---|---|
| 測りたい量／測定する領域 | 領域内の平均輝度／核 |
| 領域の決め方／測定する蛍光チャンネル | 核染色から核を検出する／GFP |
| 測定に使う画像 | 2DグレースケールTIFF / OME-TIFF |
| 核染色チャンネル | ある（この例はDRAQ） |
| まず確認したいこと | 測定値と分布を確認したい |
| GFPによる陽性選別 | 行わない |

背景と撮影条件は画像・記録に合わせて答え、不明な項目は未確認にする。候補の **「核染色からの核検出・測定」** を選んで「この計画で作業を作成」へ進み、作業名を入力して作成する。

公開サイトで先に計画した場合は、計画メモを保存して作業画面で読み込む。計画は、実画像の確認を済ませるものではない。

## 3. 画像とチャンネルを対応させる

1. 「画像を登録」で A01 の 2 枚を登録する。
2. 「チャンネルを追加」で 2 つにし、`A01-dapi.tif` の表示名・染色を **DRAQ**、`A01-gfp.tif` を **FKHR-EGFP** にする。
3. 各画像と表示名の対応を確認してから「この視野を登録」へ進む。分からない画素サイズや実験情報は空欄にする。
4. 「計画と実画像の対応」では、測る値に **FKHR-EGFPの平均（背景補正）** を選ぶ。ファイル名だけで染色を決めない。

背景補正平均は、核内の画素の平均から、そのチャンネルで選んだ背景 ROI の中央値を引いた値。補正後の負の値も保持する。

## 4. 1 視野で試し、領域を確認する

1. 核の検出に DRAQ を選び、核染色であることを確認する。
2. 画像上部でチャンネルを切り替え、それぞれ「背景」を選ぶ。細胞や測定領域と重ならない場所を 3 点以上の多角形で囲み、「背景を確定」する。適切な背景を選べない場合は、撮影条件や測定方法を見直す。
3. 両チャンネルを確認したら **「この視野で検出を試す」** から始める。
4. 輪郭を画像と重ねて確認する。必要な領域を追加・修正し、対象外の領域は削除するか、理由を記録して除外する。保存後の測定値を確認する。

核の輪郭は細胞全体の輪郭とは異なる。

## 5. 残りの視野へ進む

1. 「複数視野をまとめて登録」で、残りの A06・A12 だけを選ぶ。

   | チャンネル | 選ぶ 2 ファイル | 取り除く末尾文字 |
   |---|---|---|
   | DRAQ | `A06-dapi.tif`、`A12-dapi.tif` | `-dapi` |
   | FKHR-EGFP | `A06-gfp.tif`、`A12-gfp.tif` | `-gfp` |

2. 対応表で A06 と A12 の 2 行に各チャンネルが揃うことを確認し、画像対応と実験情報を確認して登録する。未登録行が残った場合は再試行できる。成功後は **「登録した画像を確認」** で画像へ戻れる。
3. 残りの視野でも背景を確認し、**「領域を保持して全視野を測定」** へ進む。同じ検出条件なら、先ほど修正した領域を保持できる。条件を変えて再検出するときは、対象範囲と修正領域の扱いを確認する。

## 6. 測定値の分布を図にする

1. 全視野の領域・背景・採否を確認する。「未反映の変更」が出たら **「背景・除外を反映して再測定」** を実行し、完了後に品質確認を完了する。
2. **「分布と図」** でチャンネルと指標を確かめ、図を作成する。独立した反復実験か不明でも、測定値の分布は確認できる。

図の各点は 1 核の測定値、四角はその視野内の中央値。独立実験の平均や信頼区間を示すものではない。

この練習では、A01・A06・A12 を独立した生物学的反復とは仮定せず、群間の有意差を調べない。細胞数や視野数は独立反復数の代わりにならない。

## 7. 図と根拠を一緒に保存する

1. SVG または PDF と **「図の元データ」** を保存する。全チャンネルの測定 CSV は、次の解析パッケージに含まれる。結果画面から元画像へ戻り、視野・領域 ID・測定値の対応を確認できる。
2. **「保存と履歴」** から解析パッケージを保存する。領域、測定値、条件、Methods などがまとまる。原画像は既定では含まれないため、別途保管するか、含める設定を明示して選ぶ。

整った図が出力できても、領域定義や実験デザインの妥当性は研究者が確認する。

## 8. 保存期限と終了

画像と解析結果は、PC 内の Cytellect 専用の保存先に置かれる。保存期限はインストールの設定で決まる。

| 設定 | 保存期限 |
|---|---|
| 削除操作まで保持（Windows 版の既定） | 作業画面で削除するまで残る。必要な結果は書き出し、別の媒体にもバックアップする |
| 24 時間削除（Windows 版で選択した場合、Docker 版の既定） | **最後の明示的な操作から 24 時間**。画面を開いたままにするだけでは延長されない。必要な成果物は期限前に保存する。終了中に期限を迎えたデータは、次回起動時に削除される |

終了するときは、Windows 版は起動・停止ウィンドウを、Docker 版は `.\scripts\docker-desktop.ps1 Stop` を使う。ブラウザのタブを閉じるだけでは、解析は止まらない。

研究画像の解析は Windows 版・Docker 版で行う。公開サイトは LP、計画を立てる `/plan`、解析例の `/demo` で構成する。`/demo` は本番と同じ解析ワークスペースを登録済みの公開画像でサーバーレスに動かすもので、画像は追加できない。公開サイトの `/workspace` は `/demo` へ転送される。私有画像をクラウド上で処理する提供形態は今後の対応。
