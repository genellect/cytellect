# 解析ワークスペース仕様（2026-10-06 確定案・実装前レビュー用）

PR #42 の引継ぎ、2026-10-06 のオーナーとの議論、既存要件（`docs/requirements.md`、`docs/workspace-redesign.md`、`docs/interface-design.md`）、現行コードの調査結果をもとにまとめた実装前の仕様です。研究データ・非公開資料の内容は含めていません。

## 0. 目的と優先順位

1. **研究者が迷わず使える解析画面を作る（最優先）。**
   - 画像の追加 → 核のマスク → 目的に沿った手法 → 確認・修正 → 比較・図 を、1画面で完結させる。
2. **研究者が手法を見て、選び、直せるようにする。**
   - 手法が勝手に実行される状態をなくす。
   - 意味の分からない選択肢を並べない。
3. **測定の科学的な正しさを確保する。** 対象は、核小体の定義、核質の導出、マスクの修正、GFP の判定、図の出力。
4. **ローカル PC を使わずに完了できる実装を先に行う**（第 8 章）。

## 2. 研究者の作業の流れ

```
画像を追加
 → 視野・チャンネルの自動整理（曖昧な点だけ 1 回確認）
 → 核の自動検出（全視野、裏で進む）・輪郭表示 → その場で修正
 → 目的を選ぶ／AI に伝える → 解析方法カードに手法が入る
 → 代表視野で自動試行 → 輪郭と値を確認・修正 → 「全視野に適用」
 → 結果（表・分布図）→ 比較の設計（必要な情報だけ質問）→ 比較を計算
 → 図を編集 → 保存（ZIP）
```

- ウィザードは作らない。どの段階からでも前の段階を修正でき、修正した部分に依存する結果だけを「更新が必要」にする。
- エラーが起きても作業全体はリセットしない。失敗した視野だけに状態を表示する。

## 3. 画面仕様

### 3.1 レイアウト（デスクトップ 1280〜1920 px、画面全体を使い、ページ全体はスクロールしない）

| 領域 | 幅 | 内容 |
|---|---|---|
| ヘッダー（高さ 48 px） | 全幅 | ワークスペース名、処理状況（例：「核 12/40 視野」）、画像を追加、書き出し、設定 |
| 左：視野一覧 | 200 px（折りたたみ可） | サムネイル（核チャンネル）、視野名、状態アイコン、群・撮影日のタグ、絞り込み |
| 中央：画像 | 残り全部 | 画像ビューア（3.2） |
| 右：操作パネル | 360〜400 px | タブ「方法／結果／比較・図」 |
| 下：測定表 | 開くと高さ 30% | 測定表（3.8）。閉じたときはタブ 1 行だけ |

- 1280 px 幅のとき、画像の領域は約 700 × 650 px になる。
- タブレットでは右パネルを重ねて表示する。モバイルは閲覧を優先する。

### 3.2 画像ビューア（`FieldImage.tsx` を土台にする）

- 縦横比を保ち、中央領域の高さいっぱいに表示する。
- 操作：ホイールで拡大縮小、ドラッグで移動、`1` で等倍、`0` で全体表示。
- チャンネル：チャンネルごとの表示 ON／OFF と色。合成表示または単色表示。表示用の輝度レンジは画像の脇に小さく出す（A13）。
- 輪郭レイヤー：核・核小体・GFP 陽性・背景 ROI を、それぞれ表示 ON／OFF できる。
  - **レイヤーの切り替えは表示だけを変え、保存はしない（N01）。**
- 画像の上に浮かぶ道具バー：選択、追加（描く）、描き直し、削除、結合、分割、除外、元に戻す、やり直し。
  - ショートカット：`V` 選択、`A` 追加、`R` 描き直し、`Del` 削除、`M` 結合、`S` 分割、`X` 除外、`Ctrl+Z`／`Ctrl+Shift+Z`。
- 核をクリックすると、その核の値を右パネル（結果タブ）と測定表で強調する。
- 比較表示はトグル。同じ視野のチャンネルを並べるか、複数の視野を並べる（最大 4）。拡大率と位置は連動する。

### 3.3 方法タブ：目的と解析方法カード

**(a) 目的の選択**

最上段は「何を調べますか」という一文と、AI への入力欄（3.7）。

選択肢は、研究者の問いの言葉で 5 つにする。

| 目的 | 主な出力 |
|---|---|
| 核の大きさ・核内のシグナル量を比べる | 核の面積、平均輝度・積分輝度 |
| 核小体からのタンパク質の移動（核小体ストレス）を調べる | 核質/核小体の比、核小体の面積 |
| 核小体の数・大きさを比べる | 核あたりの核小体数・面積・面積比 |
| 自分で描いた領域・既存マスクで測る | 面積、輝度 |
| 2 つの量の関係を調べる | 相関 |

「GFP 陽性の細胞だけで解析する」は、どの目的にも付けられる条件スイッチにする。

**(b) 解析方法カード**

目的を選ぶと、手順がカードとして並ぶ。目的「核小体からの移動」の例：

| 手順 | 1 行の説明（主画面に出す） | 状態 | 操作 |
|---|---|---|---|
| 1 核 | DAPI から核を自動検出（StarDist） | 完了 40/40・修正 3 | 輪郭を見る |
| 2 核小体 | DAPI の暗い部分を核小体とする | 代表視野で試行済み | 輪郭を見る／定義を変える |
| 3 背景 | 背景領域の輝度中央値を差し引く | 未設定 | 背景を描く（第 9 章 Q1） |
| 4 測る値 | NCL：核質/核小体の比（log2）、核小体の面積 | ― | 測る値を変える |
| 5 対象 | GFP 陽性の核に限る（陰性細胞を基準にする） | 基準未設定 | 基準を選ぶ |
| 6 比較 | 独立した実験を n とする | 情報不足 | 必要な情報を入力 |
| 7 図 | 実験単位の点＋細胞の分布 | ― | 図を開く |

- 手順ごとに、操作は 1 つか 2 つの小さなボタンにする。大きな CTA を縦に並べない。
- **カードの最下部に「全視野に適用」を置く。**手順 2〜5 の確定を一度に行うのは、このボタンだけ。
- 設定を変えると、影響を受ける手順の状態が「更新が必要」になる。結果は自動では消さず、「旧」の印を付けて表示を続ける。
- 「定義を変える」は、手順の下に、その場で開くフォームにする。選択肢には必ず 1 行の説明を付ける。

  例：核小体の定義元
  - **DAPI の暗い部分**：核小体は DNA が少ないため暗く写る。NCL が移動しても使える。
  - **マーカー（UBF／FBL など）**：核小体の中心部を示すマーカーで決める。マーカーの品質を確認したうえで使う。
  - **NCL の明るい部分**：旧解析の再現用。NCL がストレスで移動すると誤る。

**(c) 手法の詳細シート**

各手順の「手法の詳細」から、右からスライドして開く。

- 何をしているか（3〜5 行）
- 設定値（編集できるもの）
- 版
- 根拠の文献（リンク）
- 文献から変えた点とその理由
- 既知の限界

主画面に文献を並べることはしない（N02）。

### 3.4 結果タブ

- 選んだ核について：面積、各チャンネルの平均・積分（元の値と補正後の値）、核小体の数と面積、比、GFP の判定と理由。
- 選んだ視野について：核の数、除外の数と理由、欠測の数と理由。
- 全体について：視野ごとの分布の小さな図（自動で作る記述図、U07）。
- 値はすべて API が返したものを表示する。ブラウザでは計算しない。

### 3.5 比較・図タブ

- **比較の設計**：群、独立した実験単位、対応の有無、撮影日。不足している項目だけを質問する。既定値は入れておく。
- 撮影日と条件が重なっている場合や、群あたりの実験単位が少ない場合は警告を出す。
- 検定：設計から既定の検定を 1 つ示し、変更もできる。各選択肢には 1 行の説明を付ける。
- 「比較を計算」は明示的な操作で行う（S10）。
- 図の編集：図の種類（実験単位の点／対応の線／箱ひげ＋点／バイオリン＋点／ヒストグラム／散布図）、軸名、範囲、目盛、寸法（89／183 mm または任意）、文字の大きさ、群の順番。
  - スタイルを変えても、再解析・再検定はしない。
- 保存は 1 回の操作で、ZIP に SVG・PDF・CSV・英語の legend・Methods をまとめる（N04）。

### 3.6 表示する言葉の規則

- 操作名と対象をはっきり書く（例：「輪郭を見る」「全視野に適用」「比較を計算」）。標語・感情的な文言は使わない。
- 内部 ID、版番号、ハッシュは主画面に出さない。履歴・手法の詳細にだけ表示する。
- 図に入る文字はすべて英語にする。
  - 群名・チャンネル名が英数字以外を含む場合、保存時に英語名の入力欄を出す。
  - 指標名と単位は、サーバー側で英語に固定する。

### 3.7 AI

- 入力欄は方法タブの最上段に置く。最初は 2 行で、フォーカスすると 8 行以上に広がる。会話の履歴は欄の下に積む。
- 目的の文が空でも、画像があれば送信できる（handoff 要件 12）。
- **送信のたびに同意は求めない。**AI 機能の ON／OFF と画像プレビューの送信 ON／OFF は設定で切り替える。送信範囲は初回と設定画面に表示する。
- 応答は**構造化された設定**として受け取り、ローカルで検証したうえで、解析方法カードに直接反映する。
  - 反映される項目：目的、核チャンネル、核小体の定義元、測る値、GFP の条件、比較の設計で不足している情報、図の種類。
  - AI が変えた手順には「AI が選択」の印と、選んだ理由（1 行）を付ける。研究者はどの手順でも変更できる。
- 反映されると、代表視野での試行が自動で始まる。全視野への適用は研究者が押す。
- 画像を追加しただけでは AI を呼ばない。AI が使えないとき（失敗・上限超過）でも、手動の目的選択で全機能を使える（L06）。

### 3.8 測定表（下部）

- 1 行は 1 核。列は、視野・群・核 ID・面積・選んだ指標・GFP 判定・状態。
- 行を選ぶと、画像上でその核を強調する。図の点を選ぶと、元の視野と領域を開く（S11）。
- CSV の書き出しは、表の右上から行う。

## 4. 自動にするもの・明示にするもの

| 事象 | 扱い |
|---|---|
| 画像の追加 | 自動：ワークスペースの作成、視野・チャンネルの整理、重複の警告（N05） |
| 核チャンネルの特定 | 自動（メタデータ、名前）。曖昧なときだけ、サムネイルを 1 回クリックしてもらう（セット全体に対して 1 回） |
| 核の検出 | **自動で全視野を処理**。選んでいる視野から先に進める。検出した核は「自動」状態の作業版になる。修正すると「修正済み」になる |
| 目的・手法の選択 | 研究者が選ぶか、AI が選んでカードに反映する |
| 代表視野での試行（核小体・測る値など） | 手法が決まった時点で自動 |
| 全視野への適用（＝採用） | **明示**：「全視野に適用」 |
| マスクの修正 | 操作ごとに保存（新しい版として記録）。依存する結果だけを「更新が必要」にする |
| 比較の計算 | **明示**：「比較を計算」 |
| 記述図（分布） | 測定が終わった時点で自動 |
| 図のスタイル変更 | 表示だけを変える（再計算しない） |
| 表示の切り替え・再読み込み | **何も書き込まない**（N01） |

## 5. 解析仕様

### 5.1 核

- Fiji StarDist 2D Versatile（A01）。開始値は、パーセンタイル 1〜99.8、確率 0.5、NMS 0.3。
- 処理できる上限（長辺 2048 px、270 万画素）を超える画像は、検出用の複製だけを縮小し、輪郭は元画像の座標に戻す（I07、既存実装）。
- **縮小したことと倍率を、手法の詳細と Methods に明記する。**（現状は記録の中にしか残らない。）

### 5.2 核小体（定義元を研究者が選ぶ）

| 定義元 | 手順（文献に沿う） | 状態の扱い |
|---|---|---|
| DAPI の暗い部分（既定） | Kodiha 2011。核ごとに、平滑化した DAPI の中央値に対する比でしきい値を決める。核の縁の帯を除く。大きさの範囲（µm²）、solidity、核あたりの個数で絞り込む。DAPI だけで決めると核小体が小さめに出る（論文の報告で約 2/3）ことを、手法の詳細に記載する | 候補あり／候補なし／判定不能／失敗 |
| マーカー（UBF／FBL など） | Potapova 2023。背景を除去し、σ = 0.7 px で平滑化し、核ごとに最小〜最大の 40% をしきい値にし、4 px 未満を除く。マスクは「FC／rDNA で定義」と表示し、マスクを膨らませる処理はしない | 品質確認（5.2.1）に通らない場合は使えない |
| NCL（旧解析の再現専用） | 既存の版 1.0／1.1（核ごとの Otsu または手動） | 循環性の警告を常に表示 |

- 実装方法：既存の `compartment_engine.py` と `CytellectEngine.java` の DAPI 低値の分岐を改修し、新しい検出プロトコルの版として追加する。古い版は変更しない。
- 定義元と設定は、比較するすべての視野で同じにする。視野ごとに違う設定での比較は拒否する。

#### 5.2.1 マーカーの品質確認

- 文献に基づくもの：DAPI の暗い部分の中に点状に写る。Pol I 阻害下では、核小体の縁に集まる cap の形になる。siRNA で消える（HPA の基準）。
- 推論によるもの：細胞質のシグナルが低い。GFP と画素単位で相関しない。単染色の対照と GFP だけの対照で、蛍光の漏れ込みがない。
- 確認結果は手法の詳細に表示し、基準を満たさないときはマーカーを選べないようにする。

### 5.3 指標

| 区分 | 指標 | 根拠 |
|---|---|---|
| 主指標 | NCL の核小体と核質の平均輝度の比（White 2019）。表示は log2(核質 ÷ 核小体)（値が大きいほど核質に移動）。背景補正後の値を使い、ε は使わない。無効なら欠測とし理由を記録する | White 2019、A07 |
| 補助 | 積分輝度の比（Potapova 2023）＋核小体の面積 | Potapova 2023 |
| 補助 | 核あたりの核小体数・面積、核小体/核の面積比 | Farley-Barnes 2018、Mizielinska 2017、Aladesuyi Arogundade 2021 |
| 探索的 | 核ごとの CV（核小体の検出を使わない） | Sutton 2021（1 報のみ） |
| 旧版の再現 | 核全体/高 NCL の log2（ε あり） | A08（別レシピ） |

- 核質は「採用した（修正後の）核小体」を核から引いて求める。現状は検出をやり直しているので改修する（`services/worker/.../regions.py:300-308`）。
- 今の画面の経路（region-2d）には、異なる版の領域どうしで比を求めるサーバー側の計算がない。既存の `measurement.py:45-147` を使って追加する。

### 5.4 GFP

- **陽性の判定**：陰性対照モードでは、指定された対照細胞（同じ撮影日）の分布からしきい値を計算する。現状は、外から与えた値を使うだけ。Otsu と手動は「探索的」と表示する（S01）。
- **扱い**：GFP は回帰の共変量として扱い、分母にはしない。GFP の範囲をそろえた比較も出す。
- **任意の比較**：同じ視野の GFP 陽性細胞と陰性細胞の比較。

### 5.5 統計と図

- 統計は、既存の共通統計の実装（S10、S16、S17）をそのまま使う。
- 図：自動の説明文（legend）を英語で生成し、ZIP に必ず含める。説明文には、点が何を表すか、各段階の n、検定、エラーバー、除外の内容を書く。既存の `_caption` を流用する。
