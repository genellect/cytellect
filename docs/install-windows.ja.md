# Windows版のインストールと更新

Windows PC に Cytellect の配布版を導入し、起動・更新・アンインストールする手順。

| 項目 | 内容 |
|---|---|
| 対象 | Windows で Cytellect を使う研究者 |
| 対象版 | 0.1.0-local.19 以降。インストーラー（`Cytellect-Setup-<版>.exe`）は、それを含む最初の版から。0.1.0-local.20 までは ZIP 版だけ |
| 必要な権限 | 不要。コマンド入力も管理者権限も使わない |
| 事前に用意するもの | Cellpose（GPU）と解析提案を使う場合は、オーナーが許可したメールアドレス（作業画面でログインする。[手順 5](#5-クラウド機能を有効にするログイン)）。ログインのない版では、管理者から受け取るクラウド GPU の接続先と接続キー（[クラウド GPU で Cellpose を動かす](cloud-gpu.ja.md)） |

解析に必要なものは、ユーザー専用のフォルダー（既定は `%LOCALAPPDATA%\Cytellect`）にまとめて用意する。システムの Python、PATH、既存の Fiji は変更しない。核小体・細胞の自動検出（Cellpose）は、PC の CPU では 1 視野に数十分かかるため、クラウドの GPU で実行する。

## 1. 動作環境

| 項目 | 必要な条件 |
|---|---|
| OS | Windows 10 または 11 の 64 ビット版（x64）。ARM 版 Windows には対応しない |
| メモリ | 8 GB 以上（16 GB を推奨） |
| 空き容量 | 6 GB 以上を推奨。約 2.5 GB を解析環境が使い、残りが研究データの保存領域になる。インストーラーは、始める前に空き容量を確かめる（初回は約 4 GB とインストーラーの大きさ、更新は約 1.5 GB とインストーラーの大きさ） |
| ネットワーク | インストーラーは Python・解析ライブラリ・Fiji を同梱しており、インストール中は通信しない。ZIP 版は初回セットアップと更新のときに約 1 GB を取得する。作業画面は、新しい版の有無を GitHub に確かめる（研究データは送らない）。Cellpose を使う解析では、検出に使う画像をクラウド GPU に送る。それ以外の解析中は通信しない |
| 取得先 | インストーラーのダウンロードと更新：github.com、release-assets.githubusercontent.com、api.github.com。ZIP 版は、これに加えて www.python.org、pypi.org、files.pythonhosted.org、downloads.imagej.net、sites.imagej.net、repo.maven.apache.org。Cellpose と解析提案を使う場合は `api.cytellect.app`（ログインした場合）、または管理者から受け取ったクラウド GPU の接続先（Modal の場合は `….modal.direct`）も必要。学内ネットワークで制限がある場合は、管理者にこれらの許可を依頼する |

## 2. ダウンロードと確認

1. [Cytellect のサイト](https://cytellect.app/)の「Cytellectをダウンロード」、またはリリースのページから、インストーラー `Cytellect-Setup-<版>.exe`（約 1.07 GB）を保存する。インストーラーがない版では `Cytellect-<版>-windows-x64.zip` を保存し、[3.2](#32-zip-版のセットアップ) に進む。
2. 研究室で求められている場合は、改ざんがないことを確認する。PowerShell で次を実行し、表示された値がリリースのページの `.sha256` ファイルの値と一致することを確かめる。

   ```powershell
   Get-FileHash "$env:USERPROFILE\Downloads\Cytellect-Setup-<版>.exe" -Algorithm SHA256
   ```

## 3. インストール

### 3.1 インストーラー

1. 保存した `Cytellect-Setup-<版>.exe` を開く。
   - 管理者権限・コマンド入力・インストール先の選択は求めない。インストール先は `%LOCALAPPDATA%\Cytellect` に決まっている。
   - 「Windows によって PC が保護されました」と表示されたら、「詳細情報」を押し、表示された「実行」を押す。これはセキュリティの設定を変える操作ではなく、この 1 回だけ実行を許可する操作。
   - Smart App Control（スマート アプリ コントロール）で止められた場合は、画面からは許可できない。設定を変えずに、オーナーに連絡する（配布前の実機確認〔段階 0〕で確かめている項目）。
2. 始める前に、OS（Windows 10 バージョン 1809 以降または Windows 11、64 ビット版）、メモリ（8 GB 以上）、空き容量を確かめる。満たさない場合は、理由と次に行うことを表示し、何も変えずに終わる。空き容量が足りない場合は、空きを作ってからもう一度開く。
3. 「インストール」を押す。「Cytellect を準備しています（約 5〜10 分）」と、いま行っている段階が表示される。
4. 終わると、インストーラーの最後の画面に「インストールが完了しました」と表示され、作業画面がブラウザで開く。デスクトップとスタートメニューに **Cytellect** のショートカットができる。最後の画面は **完了** で閉じる。
5. 途中で閉じた、PC の電源が切れた、などで止まった場合は、同じインストーラーをもう一度開く。準備済みの部分は確認したうえで再利用し、続きから終える。
6. 作業データは、削除操作まで保持する（推奨の設定）。0.1.0-local.20 以前を同じ PC で使っていた場合は、その保存先（`%LOCALAPPDATA%\Cytellect`）の作業データと設定を引き継ぐ。
7. GPU（Cellpose）と解析提案は、作業画面でログインして使う（[手順 5](#5-クラウド機能を有効にするログイン)）。管理者から受け取った接続先と接続キーを使う旧来の設定は、すでにある場合は引き継ぐ。インストーラーには接続キーの入力欄はない。

### 3.2 ZIP 版のセットアップ

1. ZIP を右クリックして「すべて展開」を選ぶ。展開先はダウンロードフォルダーなど、短いパスにする。深いフォルダーに展開すると、パスの長さの上限で失敗することがある。
2. 展開したフォルダーの **Cytellect Setup.cmd** を開く。
   - 「Windows によって PC が保護されました」と表示された場合は、配布元とファイル名を確認したうえで「詳細情報」→「実行」を選ぶ（開発版は署名されていないため表示される）。
   - Windows のセキュリティ機能は無効にしない。
3. 「Cytellect セットアップ」の画面で、次を確認・入力して **セットアップ** を押す。
   - 保存先
   - **作業データの保持方法**：「作業データを自動で削除せず、削除操作まで保持する（推奨）」が最初から選ばれている。この場合、作業は作業画面で削除するまで残る。
     - 選択を外すと、最後の操作から 24 時間で作業を自動削除する。
     - 一度「保持する」でセットアップした保存先は、あとから 24 時間削除に戻せない。保持中のデータが意図せず消えることを防ぐため。
   - **クラウド GPU の接続先と接続キー**（旧来の方法）：管理者から受け取った場合だけ貼り付ける。作業画面でログインして使う場合、Cellpose を使わない場合、すでに設定済みの場合は空欄のままでよい（空欄なら、今の設定を変えない）。
4. 次の順に、取得と確認が自動で進む。初回は回線速度により 5〜20 分かかる。
   - 配布ファイルの検証
   - 解析用 Python 3.14 と解析ライブラリ
   - Fiji（核の検出、StarDist）
   - 計算の動作確認
5. 「準備完了」と表示されたら **開く** を押す。デスクトップとスタートメニューに **Cytellect** のショートカットが作られる。
   - 準備完了の表示に「Cellposeはクラウド GPU で実行します」とあれば、核小体・細胞の自動検出も使える。
   - 「クラウド GPU が未設定のため、Cellposeは使えません」とある場合は、核の検出・測定・統計・図だけが使える。管理者から接続先と接続キーを受け取り、セットアップをもう一度実行して入力する。
6. 途中で閉じたり失敗したりした場合は、同じ Cytellect Setup.cmd をもう一度実行する。取得済みで検証に合格したファイルは再利用される。

## 4. 起動と終了

- **起動**：ショートカット「Cytellect」を開く。小さな起動・停止ウィンドウに「起動の準備中」、続いて「作業画面を開いています」と表示され、ブラウザで作業画面が開く。開かない場合は **作業画面を開く** を押す。招待コードやコマンドは不要。
- **すでに起動している場合**：もう一度ショートカットを開くと、起動中であることを表示し、作業画面をブラウザで開く。
- **終了**：起動・停止ウィンドウを閉じる。ブラウザのタブを閉じるだけでは、解析は止まらない。
- **研究データの保存**：画像と結果は、この PC の保存先の `data` フォルダーだけに置かれる。Web サイトや外部の AI には送信しない。
  - Cellpose を使う検出では、検出に使う画像（と核のマスク）だけをクラウド GPU に送る。クラウド側には保存されず、結果だけが返る。ファイル名や作業名は送らない。
  - 「保持する」を選んだ場合、作業は作業画面で削除するまで残る。PC の故障や誤操作に備えて、必要な結果は保存機能で書き出し、別の媒体にもバックアップする。作業が増えると保存先の空き容量が減るため、不要になった作業は削除する。
  - 24 時間削除を選んだ場合、保存期限は最後の明示的な操作から 24 時間。終了中に期限を迎えたデータは、次の起動時に削除される。
  - 0.1.0-local.17 以前でセットアップした保存先を更新すると、それまでの 24 時間削除から「保持する」に切り替わる（更新時に選択を外さない場合）。切り替えの時点ですでに期限を過ぎていた作業は、復活せずに削除される。

## 5. クラウド機能を有効にする（ログイン）

GPU による核小体・細胞の検出（Cellpose）と解析提案は、オーナーが許可したメールアドレスでログインすると使える。ほかの解析はログインなしで使える。

1. 初回の起動では「インストールが完了しました」と表示される。「クラウド機能を有効にする」を選ぶ。2 回目以降は、作業画面の右上の **ログイン** を押す。
2. メールアドレスを入れて **コードを送る** を押す。メールで届いた 6 桁のコードを入れて **ログイン** を押す。
   - 届かない場合は、迷惑メールのフォルダーを確認する。**コードを再送** は 60 秒後に押せる。宛先を間違えた場合は **メールアドレスを修正** を押す。
   - コードの有効期限は 10 分。誤りが続くと入力できなくなるため、そのときはコードを再送する。
3. 右上にメールアドレスと「GPU・解析提案：利用可」が表示されれば完了。押すと今月の利用量とログアウトが表示される。
4. 許可されていないメールアドレスでは、オーナーへの申請になる。作業画面の上部に「承認待ち」が表示され、承認されると「承認されました。ログインを続ける」に変わる（メールでも知らせる）。待つ間も、このPCでの解析は使える。

ログインは PC ごとに保持し、作業画面からログアウトできる。PC に残るのは保存先の `settings\cloud-account.json`（研究データの `data` とは別。この利用者だけが読める）にある端末用のトークンで、画面やログには出ない。管理者から受け取った接続先と接続キーを設定済みの PC では、Cellpose にはその設定が優先して使われる。ログイン中は、Cellpose を常にクラウドの GPU で実行する。

GPU の起動を待つ時間も、GPU の利用時間に数える。Cellpose を選んだときの自動の起動は作業画面を開くたびに 1 回だけで、2 分で終わらなければ「もう一度試す」を表示する。

Cellpose の検出方法を選ぶと、停止しているクラウド GPU の起動を始め、「GPU を起動しています」と表示する。起動には数分かかることがある。

## 6. 動作確認（初回のみ）

1. 作業画面で公開の練習画像（[BBBC013 練習用 ZIP](https://github.com/genellect/cytellect/releases/download/v0.1.0-local.11/Cytellect-BBBC013-practice-v1.zip)）を登録し、核を検出できることを確認する。操作の流れは[はじめての画像解析](quickstart.ja.md)にある。
2. NCL などの核小体染色の画像を使う場合は、核小体の検出方法で Cellpose を選び、1 視野で試してから全視野に進む。しばらく使っていないとクラウド GPU が停止しているため、最初の 1 視野は起動を待つ分だけ数分かかる。
3. 練習画像の結果は操作の確認用で、研究画像での検出精度を保証するものではない。

## 7. 更新（新しい版への入れ替え）

インストーラー版は、次のどちらかで更新する。

- **作業画面から**：新しい版があると作業画面に「更新があります」と表示される。押すと、新しい版を GitHub から取得し、改ざんがないことを確かめてから、今の版の横に用意する。確認が終わると Cytellect が自動で再起動して新しい版になる。解析を実行している間は更新できない（終わってから押す）。更新の途中で解析が始まった場合は、新しい版を用意したうえで、次に Cytellect を起動したときに切り替わる。
- **インストーラーで**：新しい版の `Cytellect-Setup-<版>.exe` を開く。起動中のままでもよい。次に Cytellect を開いたときから新しい版になる。

更新に失敗した場合は、元の版のまま使える。新しい版が起動しなかった場合は、更新の直前のデータベースに戻して元の版で起動し、「元の版で起動しました。あとでもう一度更新してください」と表示する。

ZIP 版の更新は次の手順で行う。

1. 起動・停止ウィンドウを閉じて、Cytellect を終了する。
2. 新しい版の ZIP をダウンロードし、確認と展開を行う（手順 2）。作業画面に「更新があります」と表示される版では、**更新する** を押して更新できる。
3. 新しい版の **Cytellect Setup.cmd** を開き、**同じ保存先のまま**セットアップを押す。保存先を変えると、別のインストールとして扱われる。

どちらの方法でも、更新時の動作は次のとおり。

   - 研究データ（`data` フォルダー）は保持される。データベースは新しい版に合わせて自動で更新される。
   - Python・Fiji は、内容が変わらない限り再取得しない。
   - クラウド GPU の設定は引き継がれる。接続先や接続キーを変える場合だけ入力する。
   - 新しい版の確認が終わるまで、旧版は残る。直前の版は保持され、それより古い版は自動で整理される。
   - 0.1.0-local.11 以前が作った「Cytellect 0.1.0-local.11-…」のような版名付きのショートカットは、新しい版の準備が完了した後に自動で削除される。古いショートカットから旧版を起動すると、更新済みのデータベースを開けないため。
   - 更新後は「Cytellect」のショートカットから起動する。
更新が途中で失敗した場合も、旧版とデータはそのまま残る。原因を解消して、もう一度インストーラー（または ZIP 版のセットアップ）を実行する。

## 8. 困ったとき

| 表示 | 対処 |
|---|---|
| インストーラーを開くと「Windows によって PC が保護されました」 | 「詳細情報」を押し、表示された「実行」を押す。セキュリティの設定を変える操作ではなく、この 1 回だけ実行を許可する操作 |
| 「Windowsの保護機能により実行が拒否されました（4551）」、コード `windows_application_control_blocked`、または Smart App Control（スマート アプリ コントロール）で止められた | PC のアプリケーション制御が配布物の一部を拒否している。画面からは許可できない。設定を無効にせず、オーナーに連絡する（配布前の実機確認〔段階 0〕で確かめている項目）。研究室の管理者が設定した制御の場合は、PC の管理者にも配布物の確認を依頼する |
| インストーラーの「空き容量が不足しています」「メモリーが不足しています」「この Windows には対応していません」 | 何も変更されていない。表示された条件を満たしてから、もう一度インストーラーを開く |
| インストーラーの「インストールを完了できませんでした」 | 次の順に試す。(1) もう一度インストーラーを開く（続きから再開する）、(2) PC を再起動してから開く、(3) ダウンロードし直して開く（「ファイルが壊れているか、一部が欠けています」の場合は最初に行う）。それでも続く場合は、表示された詳細を添えて PC の管理者に相談する |
| 「準備を停止しました（…）」（ZIP 版） | ネットワーク接続と空き容量を確認し、Cytellect Setup.cmd を再実行する。Fiji の取得は、通信の一時的な切断や混雑（HTTP 429・5xx）なら自動で再試行してから停止する |
| 作業画面で「Cellpose（核小体・細胞の検出）はクラウドの GPU で動きます」 | ログインしていない。右上の **ログイン** からクラウド機能を有効にする（[手順 5](#5-クラウド機能を有効にするログイン)） |
| 「承認待ち」が続く | オーナーの承認を待つ。急ぐ場合はオーナーに連絡する。待つ間も、このPCでの解析は使える |
| 「利用が停止されています」 | オーナーが許可を取り消している。オーナーに問い合わせる |
| 「クラウド機能を使うには、もう一度ログインしてください」 | ログインの期限が切れた。右上の **ログイン** から、もう一度ログインする |
| 「今月の GPU の利用上限に達しました」 | 表示された日に再び使える。それまでは、このPCでの解析を使う |
| 「メールを送れませんでした」 | 時間をおいて、もう一度コードを送る |
| 「しばらくしてからもう一度試してください（約 N 時間後）」 | コードの送信や誤りが続いたため、一時的に止まっている。表示された時間の後に、もう一度ログインする。待つ間も、このPCでの解析は使える |
| 作業画面で「Cellposeの実行環境がありません」（ログインのない版） | クラウド GPU が未設定。管理者から接続先と接続キーを受け取り、Cytellect Setup.cmd を再実行して入力する |
| 「クラウドGPUに接続できませんでした（接続キーが無効です）」、または「クラウドGPUが利用を認めませんでした」 | ログインしている場合は、右上の表示でログインの状態を確かめる。接続キーを使っている場合は、管理者から新しい接続キーを受け取り、セットアップで入力し直す |
| 「クラウドGPUの起動が時間内に終わりませんでした」 | 停止していたクラウド GPU の起動に時間がかかっている。数分おいて、もう一度実行する |
| 「クラウドGPUの版がこのCytellectと一致しません」 | 管理者に、クラウド GPU をこの版に更新するよう依頼する |
| 「Cytellectは既に起動しています」 | 作業画面がブラウザで開く。開かない場合は、起動・停止ウィンドウの **作業画面を開く** を押す。ウィンドウが見当たらない場合は PC を再起動する |
| 起動時に「接続先（ポート）が使用中」 | 他のソフトがポート 8765 を使っている。**再試行** を押す。PC を再起動しても続く場合は管理者に相談する |

## 9. アンインストール

1. Cytellect を終了する。起動中はアンインストールできない。
2. 必要な結果を書き出したことを確認する。
3. Windows の「設定」→「アプリ」→「インストールされているアプリ」で **Cytellect** を選び、「アンインストール」を押す。
4. 「研究データも削除しますか？」と確認される。
   - **いいえ**（既定）：解析環境とショートカットだけを削除する。研究データと設定は `%LOCALAPPDATA%\Cytellect` に残り、もう一度インストールすると引き継がれる。
   - **はい**：研究データも削除する。元に戻せない。

ZIP 版だけを使っていて「アプリ」に Cytellect がない場合は、保存先フォルダー（既定は `%LOCALAPPDATA%\Cytellect`）と、デスクトップ・スタートメニューの「Cytellect」ショートカットを削除する。保存先を削除すると、研究データも削除される。
