# Windows版のインストールと更新

Windows PC に Cytellect の配布版を導入し、起動・更新・アンインストールする手順。

| 項目 | 内容 |
|---|---|
| 対象 | Windows で Cytellect を使う研究者 |
| 対象版 | 0.1.0-local.19 以降 |
| 必要な権限 | 不要。コマンド入力も管理者権限も使わない |
| 事前に受け取るもの | Cellpose を使う場合は、管理者からクラウド GPU の接続先と接続キー（管理者の準備は[クラウド GPU で Cellpose を動かす](cloud-gpu.ja.md)） |

解析に必要なものは、ユーザー専用のフォルダー（既定は `%LOCALAPPDATA%\Cytellect`）にまとめて用意する。システムの Python、PATH、既存の Fiji は変更しない。核小体・細胞の自動検出（Cellpose）は、PC の CPU では 1 視野に数十分かかるため、クラウドの GPU で実行する。

## 1. 動作環境

| 項目 | 必要な条件 |
|---|---|
| OS | Windows 10 または 11 の 64 ビット版（x64）。ARM 版 Windows には対応しない |
| メモリ | 8 GB 以上（16 GB を推奨） |
| 空き容量 | 5 GB 以上を推奨。約 2.5 GB を解析環境が使い、残りが研究データの保存領域になる |
| ネットワーク | 初回セットアップと更新のときに、約 1 GB を取得する。Cellpose を使う解析では、検出に使う画像をクラウド GPU に送る。それ以外の解析中は通信しない |
| 取得先 | github.com、release-assets.githubusercontent.com、www.python.org、pypi.org、files.pythonhosted.org、downloads.imagej.net、sites.imagej.net、repo.maven.apache.org。Cellpose を使う場合は、管理者から受け取ったクラウド GPU の接続先（Modal の場合は `….modal.direct`）も必要。学内ネットワークで制限がある場合は、管理者にこれらの許可を依頼する |

## 2. ダウンロードと確認

1. [Cytellect のサイト](https://cytellect.vercel.app/)の「Cytellectをダウンロード」、またはリリースのページから `Cytellect-<版>-windows-x64.zip` を保存する。
2. 研究室で求められている場合は、改ざんがないことを確認する。PowerShell で次を実行し、表示された値がリリースのページに記載の SHA-256 と一致することを確かめる。

   ```powershell
   Get-FileHash "$env:USERPROFILE\Downloads\Cytellect-<版>-windows-x64.zip" -Algorithm SHA256
   ```

3. ZIP を右クリックして「すべて展開」を選ぶ。展開先はダウンロードフォルダーなど、短いパスにする。深いフォルダーに展開すると、パスの長さの上限で失敗することがある。

## 3. セットアップ

1. 展開したフォルダーの **Cytellect Setup.cmd** を開く。
   - 「Windows によって PC が保護されました」と表示された場合は、配布元とファイル名を確認したうえで「詳細情報」→「実行」を選ぶ（開発版は署名されていないため表示される）。
   - Windows のセキュリティ機能は無効にしない。
2. 「Cytellect セットアップ」の画面で、次を確認・入力して **セットアップ** を押す。
   - 保存先
   - **作業データの保持方法**：「作業データを自動で削除せず、削除操作まで保持する（推奨）」が最初から選ばれている。この場合、作業は作業画面で削除するまで残る。
     - 選択を外すと、最後の操作から 24 時間で作業を自動削除する。
     - 一度「保持する」でセットアップした保存先は、あとから 24 時間削除に戻せない。保持中のデータが意図せず消えることを防ぐため。
   - **クラウド GPU の接続先と接続キー**：管理者から受け取ったものを貼り付ける。Cellpose を使わない場合や、すでに設定済みの場合は空欄のままでよい（空欄なら、今の設定を変えない）。
3. 次の順に、取得と確認が自動で進む。初回は回線速度により 5〜20 分かかる。
   - 配布ファイルの検証
   - 解析用 Python 3.14 と解析ライブラリ
   - Fiji（核の検出、StarDist）
   - 計算の動作確認
4. 「準備完了」と表示されたら **開く** を押す。デスクトップとスタートメニューに **Cytellect** のショートカットが作られる。
   - 準備完了の表示に「Cellposeはクラウド GPU で実行します」とあれば、核小体・細胞の自動検出も使える。
   - 「クラウド GPU が未設定のため、Cellposeは使えません」とある場合は、核の検出・測定・統計・図だけが使える。管理者から接続先と接続キーを受け取り、セットアップをもう一度実行して入力する。
5. 途中で閉じたり失敗したりした場合は、同じ Cytellect Setup.cmd をもう一度実行する。取得済みで検証に合格したファイルは再利用される。

## 4. 起動と終了

- **起動**：ショートカット「Cytellect」を開く。小さな起動・停止ウィンドウが表示され、ブラウザで作業画面が開く。招待コードやコマンドは不要。
- **終了**：起動・停止ウィンドウを閉じる。ブラウザのタブを閉じるだけでは、解析は止まらない。
- **研究データの保存**：画像と結果は、この PC の保存先の `data` フォルダーだけに置かれる。Web サイトや外部の AI には送信しない。
  - Cellpose を使う検出では、検出に使う画像（と核のマスク）だけをクラウド GPU に送る。クラウド側には保存されず、結果だけが返る。ファイル名や作業名は送らない。
  - 「保持する」を選んだ場合、作業は作業画面で削除するまで残る。PC の故障や誤操作に備えて、必要な結果は保存機能で書き出し、別の媒体にもバックアップする。作業が増えると保存先の空き容量が減るため、不要になった作業は削除する。
  - 24 時間削除を選んだ場合、保存期限は最後の明示的な操作から 24 時間。終了中に期限を迎えたデータは、次の起動時に削除される。
  - 0.1.0-local.17 以前でセットアップした保存先を更新すると、それまでの 24 時間削除から「保持する」に切り替わる（更新時に選択を外さない場合）。切り替えの時点ですでに期限を過ぎていた作業は、復活せずに削除される。

## 5. 動作確認（初回のみ）

1. 作業画面で公開の練習画像（[BBBC013 練習用 ZIP](https://github.com/genellect/cytellect/releases/download/v0.1.0-local.11/Cytellect-BBBC013-practice-v1.zip)）を登録し、核を検出できることを確認する。操作の流れは[はじめての画像解析](quickstart.ja.md)にある。
2. NCL などの核小体染色の画像を使う場合は、核小体の検出方法で Cellpose を選び、1 視野で試してから全視野に進む。しばらく使っていないとクラウド GPU が停止しているため、最初の 1 視野は起動を待つ分だけ数分かかる。
3. 練習画像の結果は操作の確認用で、研究画像での検出精度を保証するものではない。

## 6. 更新（新しい版への入れ替え）

1. 起動・停止ウィンドウを閉じて、Cytellect を終了する。
2. 新しい版の ZIP をダウンロードし、確認と展開を行う（手順 2）。
3. 新しい版の **Cytellect Setup.cmd** を開き、**同じ保存先のまま**セットアップを押す。保存先を変えると、別のインストールとして扱われる。
4. 更新時の動作は次のとおり。
   - 研究データ（`data` フォルダー）は保持される。データベースは新しい版に合わせて自動で更新される。
   - Python・Fiji は、内容が変わらない限り再取得しない。
   - クラウド GPU の設定は引き継がれる。接続先や接続キーを変える場合だけ入力する。
   - 新しい版の確認が終わるまで、旧版は残る。直前の版は保持され、それより古い版は自動で整理される。
   - 0.1.0-local.11 以前が作った「Cytellect 0.1.0-local.11-…」のような版名付きのショートカットは、新しい版の準備が完了した後に自動で削除される。古いショートカットから旧版を起動すると、更新済みのデータベースを開けないため。
   - 更新後は「Cytellect」のショートカットから起動する。
5. 更新が途中で失敗した場合も、旧版とデータはそのまま残る。原因を解消して、もう一度セットアップする。

## 7. 困ったとき

| 表示 | 対処 |
|---|---|
| 「Windowsの保護機能により実行が拒否されました（4551）」、またはコード `windows_application_control_blocked` | PC のアプリケーション制御（Smart App Control など）が配布物の一部を拒否している。設定を無効にせず、PC の管理者に配布物の確認を依頼する |
| 「準備を停止しました（…）」 | ネットワーク接続と空き容量を確認し、Cytellect Setup.cmd を再実行する。Fiji の取得は、通信の一時的な切断や混雑（HTTP 429・5xx）なら自動で再試行してから停止する |
| 作業画面で「Cellposeの実行環境がありません」 | クラウド GPU が未設定。管理者から接続先と接続キーを受け取り、Cytellect Setup.cmd を再実行して入力する |
| 「クラウドGPUに接続できませんでした（接続キーが無効です）」 | 接続キーが無効になっている。管理者から新しい接続キーを受け取り、セットアップで入力し直す |
| 「クラウドGPUの起動が時間内に終わりませんでした」 | 停止していたクラウド GPU の起動に時間がかかっている。数分おいて、もう一度実行する |
| 「クラウドGPUの版がこのCytellectと一致しません」 | 管理者に、クラウド GPU をこの版に更新するよう依頼する |
| 「Cytellectは既に起動しています」 | 開いている起動・停止ウィンドウを使う。見当たらない場合は PC を再起動する |
| 起動時に「接続先が使用中」 | 他のソフトがポート 8765 を使っている。PC を再起動しても続く場合は管理者に相談する |

## 8. アンインストール

1. Cytellect を終了する。
2. 必要な結果を書き出したことを確認する。
3. 保存先フォルダー（既定は `%LOCALAPPDATA%\Cytellect`）と、デスクトップ・スタートメニューの「Cytellect」ショートカットを削除する。保存先を削除すると、研究データも削除される。
