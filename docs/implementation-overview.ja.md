# Cytellect でできる解析

蛍光顕微鏡画像から細胞核を検出し、測定・統計検定・論文用の図までを行います。
2026年10月時点で使える機能を、研究者の作業の順に紹介します。

## 一覧

| 段階 | できること |
|---|---|
| 画像 | 2次元の TIFF・OME-TIFF（8/16 bit）。チャンネルごとのファイル、またはマルチチャンネル OME |
| 核の検出 | StarDist 2D（蛍光核用の学習済みモデル）。結果を見ながら追加・削除・結合・分割で修正できる |
| 核小体 | NCL の Otsu しきい値、または DAPI の暗い部分から抽出 |
| GFP | 核ごとの輝度。陽性判定は手動・撮影日ごとの Otsu・陰性対照基準から選択 |
| 測定 | 面積（px・µm²）、平均・中央値・積分輝度（背景補正の前後）、核小体の数・面積割合、核質/核小体の輝度比 |
| 統計 | Welch t、対応のある t、Mann–Whitney、Wilcoxon、Welch ANOVA、Kruskal–Wallis、Pearson、Spearman。多重比較は Holm 法 |
| 図 | 細胞・視野・実験単位を重ねた分布図、箱ひげ図、バイオリン図、ヒストグラム、対応線、散布図 |
| 出力 | SVG（文字を編集可）、PDF、PNG（300 dpi）、全階層の CSV、Methods の文案、ImageJ ROI |

## 画像と核の検出

TIFF をチャンネルごとに追加すると、ファイル名から視野とチャンネルをまとめます。
ファイル名に DAPI、Hoechst、DRAQ とあれば、そのチャンネルで核を検出します。
`c1` や `w2` のような番号だけでは染色を決めず、どのチャンネルで核を検出するかを一度だけ選びます。

核の検出には、Fiji 上で動く StarDist 2D を使います。
検出のための輝度の正規化は複製に対して行い、測定には元の画素値をそのまま使います。
大きさや画像端を理由に核を自動で除くことはしません。画像端に接している核には印が付き、除くかどうかは研究者が判断します。

検出結果は画像に重ねて確認でき、核の追加・削除・結合・分割と、視野や核の除外ができます。
修正するたびに新しい版として保存され、元の結果も残ります。

## 測定

| 項目 | 内容 |
|---|---|
| 面積 | 画素数。画素サイズを確認すれば µm² |
| 輝度 | 平均・中央値・積分値。背景を引いた値は負になっても丸めない |
| 背景 | 核の外に指定した領域の中央値 |
| 核小体 | 数、核に占める面積の割合、核質と核小体の平均輝度の比（log2 も） |
| 品質の印 | 飽和画素の割合、画像端との接触、信号の弱さ |

計算できない値は 0 にせず、理由を付けて欠測にします。
背景を指定していなければ背景補正値は出さず、核小体がない核では比を出しません。
核を修正すると、その核の核小体は再確認が必要になります。

## 統計：n は細胞数ではなく実験単位

同じ皿の細胞どうしは独立ではないため、細胞数を n にすると p 値が過度に小さくなります。
Cytellect は、次の順に値をまとめ、独立した実験単位（独立に行った実験の回数や個体など）を n とします。

細胞 →（中央値）→ 視野 →（平均）→ 試料 →（平均）→ 実験単位

条件と実験単位の対応は比較のときに入力します。1つの視野が2つの条件にまたがる配置や、対応のない比較で同じ実験単位が両群に入る配置は受け付けません。

| デザイン | 検定 | 結果として出るもの |
|---|---|---|
| 2群・独立 | Welch の t 検定 | 平均の差と 95% 信頼区間、t、自由度、p |
| 2群・対応あり | 対応のある t 検定 | 差の平均と 95% 信頼区間 |
| 2群・分布を仮定しない | Mann–Whitney U | U、p、優越確率 |
| 対応あり・分布を仮定しない | Wilcoxon 符号付き順位 | 統計量、p、順位双列相関 |
| 3群以上 | Welch ANOVA または Kruskal–Wallis ＋ 事前に決めた2群比較 | 全体の検定と各比較の Holm 補正 p |
| 2つの測定値の関連 | Pearson または Spearman | 実験単位ごとの相関と p |

標本が小さいときは、すべての並べ方を数える正確な p 値を使います。
正規性の検定の結果で手法を切り替えることはせず、実験デザインに合わない組み合わせ（対応のあるデータに独立 2 群の検定など）は選べません。
1群 5 単位未満では警告を表示します。

まだ使えない手法：混合効果モデル、3条件以上の反復測定（Friedman、反復測定 ANOVA）、Tukey などの事後検定、Cohen の d、相関係数の信頼区間、FDR、検出力の計算。

## 図

| 図 | 内容 |
|---|---|
| 視野ごとの分布 | 細胞の値と視野の中央値。視野が多ければページを分け、縦軸をそろえる |
| 群の比較（従来の解析画面） | 細胞・視野・実験単位の値と、実験単位の平均±95% 信頼区間を重ねる（SuperPlot 形式） |
| 実験単位の分布 | 点、箱ひげ、バイオリン、ヒストグラム、対応線 |
| 関連 | 実験単位ごとの散布図 |

図の点を選ぶと、その細胞が写っている元画像が開きます。
寸法は Nature の 1 段幅（89 mm）・2 段幅（183 mm）と任意の寸法から選べます。配色は色覚の違いに配慮した 7 色と 9 種の記号です。
p 値は図に描き込まず、説明文と CSV に記載します。

書き出しには、図（SVG・PDF・PNG）、すべての階層の値の CSV、手法と版を記した Methods の文案、ImageJ で開ける ROI が含まれます。
一式にはファイルごとのハッシュと再計算用のスクリプトが入っており、同じ数値と図が再現されることを確認できます。

まだできないこと：複数パネルの組図、顕微鏡画像パネルとスケールバー、対数軸、配色の変更、SD・SEM のエラーバー。

## 妥当性の確認

| 確認 | 結果 |
|---|---|
| 測定値の計算 | 公開画像 3 種（BBBC007、BBBC013、4DN）で ImageJ と一致。4DN では面積・平均・中央値が完全一致、比は 10⁻¹² 以内 |
| 統計の計算 | 各検定を手計算の値や全組み合わせの数え上げと照合 |
| 核の検出 | BBBC039（Hoechst）で F1 0.92。ただしモデルの学習データと重なるため独立な評価ではない |
| 核小体の検出 | 正解付きの公開データがなく、精度は未評価 |
| 細胞単位の回帰（従来の探索用） | 差がない条件の模擬実験で偽陽性が約 32%（本来は 5%）。そのため自動提案からは外している |

計算の正しさは確認済みです。核と核小体の検出精度は、研究室の画像での検証がまだ残っています。

## 解析手順の提案（任意）

使いたい解析の目的を一文で書くと、外部の言語モデルが測定項目・検定・図の組み合わせを提案します。
送るのはチャンネルの記号と件数と目的文だけで、画像や測定値は送りません。
提案は手元で検査し、番号だけのチャンネルに染色名を付ける案や、実験単位がないのに検定する案は受け付けません。
モデルは数値を計算せず、提案は研究者が採用するまで実行されません。既定では無効です。
