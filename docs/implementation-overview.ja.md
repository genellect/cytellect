# Cytellect 実装概要：API・画像解析・統計解析・図の出力

2026年10月6日時点の `main` に実装されている内容をまとめます。計画中の機能は含めません。
各項目の詳細と根拠は、末尾の関連文書を参照してください。

## 1. 全体の構成

Cytellect は、蛍光顕微鏡画像から細胞核などの領域を検出し、測定・統計・図の作成までを一続きで行います。

| 部分 | 役割 |
|---|---|
| Web 画面（Next.js） | 画像の追加、結果の確認と修正、図の調整。数値の計算は行わない |
| API（FastAPI、SQLite） | ワークスペース、画像、解析の版、ジョブを管理する |
| 解析ワーカー | 画像処理（Fiji）、測定、統計、図の描画を行う。ネットワークから切り離して動かせる |
| 解析パッケージ（Python） | 測定・統計・図の計算をまとめた共通部品。API とワーカーが同じものを使う |

利用形態は次の3つで、どれも同じ解析パッケージを使います。

- **Web 版**：公開画像の解析例を表示します。研究画像の解析は行いません。
- **Windows 版**：利用者の PC 内で API とワーカーを動かします。
- **Docker 版**：同じ構成をコンテナで動かします。

## 2. API の設計

### 基本方針
- **数値はサーバーが持つ**：測定値・統計量・図は、すべて API とワーカーが計算して保存します。ブラウザは保存された値を表示するだけです。
- **原画像は変更しない**：検出のための前処理は複製に対して行い、測定には元の画素値を使います。
- **結果を上書きしない**：検出・修正・除外・背景の変更は、それぞれ新しい「版（revision）」として保存します。以前の版と、その版から作った結果は残ります。
- **重い処理はジョブにする**：解析・統計・書き出しは、要求を受け付けた時点で `202` とジョブ ID を返します。進み具合は `GET /v1/jobs/{id}` で確認し、取り消し（`cancel`）と再実行（`retry`）ができます。

### 認証と保護
- 招待コードを交換するとセッション Cookie が発行され、以後はそのセッションで操作します。Windows 版は PC 内だけで使う専用のセッションを使います。
- 状態を変える要求には、送信元（Origin）の確認と専用ヘッダーの確認を行います。
- ワークスペースは作成者だけが読み書きできます。他人のワークスペースは「存在しない」（404）として扱います。

### 主なエンドポイント

| 段階 | エンドポイント（抜粋） | 内容 |
|---|---|---|
| 準備 | `POST /v1/workspaces` | ワークスペースを作る |
| 画像 | `POST /v1/workspaces/{id}/region-fields` | 視野（チャンネル別の TIFF）を登録する。形式・ビット深度・寸法をここで検証する |
| 解析 | `POST /v1/workspaces/{id}/region-analyses` | 核の検出と測定を始める |
| 確認・修正 | `GET /v1/revisions/{id}/region-masks`、`POST …/region-edits` | マスクを取得し、領域を修正する |
| 測定値 | `GET /v1/revisions/{id}/region-measurements` | 領域ごと・チャンネルごとの測定表 |
| 記述統計 | `POST /v1/revisions/{id}/descriptive` | 視野ごとの分布と図を作る |
| 比較 | `POST /v1/workspaces/{id}/region-cohorts`、`POST …/common-statistics` | 条件・実験単位を割り当て、群間比較を行う |
| 書き出し | `POST /v1/revisions/{id}/export`、`GET /v1/jobs/{id}/files/{name}` | 図・表・再現用一式を出力する |
| 解析案 | `POST /v1/workspaces/{id}/proposal-drafts` | 任意。外部の言語モデルに解析手順の案を求める（4章の末尾を参照） |

### 保存と再現性
- 解析の版ごとに、レシピ・測定規約・統計手法・図の描画処理の版番号を記録します。
- 出力物には SHA-256 を付けます。書き出した一式から測定・統計・図を計算し直し、元と一致することを確認できます。

## 3. 画像解析

### 入力
- 2次元の TIFF と OME-TIFF を受け付けます。8 bit または 16 bit のグレースケールで、1辺は最大 4096 px です。
- Z 方向の枚数と時間点は、それぞれ1つに限ります。足りない画像面を0で埋めることはせず、エラーにします。
- 新しい作業画面では、1つのファイルに1チャンネルの TIFF を使います。マルチチャンネル OME は、核小体（NCL）と GFP の専用解析で、チャンネルの対応を明示した場合に限り使えます。
- **ファイル名の番号（`c1`、`w2` など）から染色の種類を決めることはありません。** どのチャンネルで核を検出するかは、ファイル名にある染色名（DAPI、Hoechst、DRAQ）か、利用者の選択で決めます。

### 核の検出
- 使うのは Fiji 上の StarDist 2D（蛍光核用の学習済みモデル）です。Fiji、モデル、関連ライブラリは版と SHA-256 で固定し、実行前に毎回照合します。
- 主な設定は、輝度の正規化（1〜99.8パーセンタイル）、確率しきい値 0.5、重なり除去のしきい値 0.3 です。
- 正規化は検出用の複製にだけ行います。検出結果は、元画像と同じ座標のラベル画像（マスク）として保存します。
- 大きさや画像端による自動除外はしません。画像端に接している領域には印を付けるだけです。

### 核小体と GFP
- **核小体**：核ごとに、次のどちらかの方法で抽出します。
  - NCL チャンネルに Otsu 法でしきい値を設定する。
  - DAPI の暗い部分（既定では下位10%）を選ぶ。
  
  結果は「候補あり」「候補なし」「判定不能（信号が一様）」「処理失敗」のいずれかとして記録します。
- **GFP**：核全体で測定します。陽性・陰性の判定は次から選びます。
  - 判定しない
  - 手動で値を指定する
  - 撮影日ごとに Otsu 法で決める
  - 陰性対照を基準にする
  
  手動・Otsu・上限による判定は「探索的」として記録します。
- 核を修正すると、その核に含まれる核小体の結果は無効になり、再確認が必要になります。
- 斑点状の構造（foci）の検出は実装していません。

### 測定値
| 項目 | 内容 |
|---|---|
| 面積 | 画素数。画素サイズが確認されている場合は µm² も出す |
| 輝度 | 平均・中央値・積分値。補正前の値と、背景を差し引いた値（負の値も残す） |
| 背景 | 核の外側に指定した領域の中央値と、そのばらつき（MAD） |
| 核小体 | 数、核に占める面積の割合、核質と核小体の平均輝度の比とその log2 |
| 品質 | 飽和した画素の割合、画像端との接触、信号の弱さ。いずれも印を付けるだけで、自動では除外しない |

計算できない値は0にせず欠測とし、理由を記録します。たとえば、背景が設定されていない場合の補正値は `background_not_established` として欠測になります。

### 修正と確認
- 領域の追加・削除・結合・分割と、視野や領域の除外ができます。除外には理由の入力が必要です。
- 統計に進めるのは、確認済みの版で、失敗した視野が残っていない場合だけです。

### 検証の状況
| データ | 確認したこと | 限界 |
|---|---|---|
| BBBC039（Hoechst） | 核検出の F1 は全体で0.92、視野平均で0.886 | 学習データと重なりがあり、独立した評価ではない |
| 4DN（DAPI と NCL） | 面積・平均・中央値が ImageJ と完全に一致し、比も一致 | 正解データがなく、核小体の検出精度は未評価 |
| BBBC007・BBBC013 | 測定値の計算が ImageJ と一致 | 検出精度の評価ではない |

計算の正しさは確認できていますが、検出精度は、独立したデータでも研究画像でもまだ検証していません。

## 4. 統計解析

### 集計の考え方
細胞は互いに独立ではありません。そこで、細胞数ではなく**独立した実験単位の数を n とします**。集計は次の順に、重みを付けずに行います。

1. 視野ごとに、細胞（領域）の値の中央値を取る。
2. 試料ごとに、視野の値の平均を取る。
3. 実験単位ごとに、試料の値の平均を取る。

この規則は `field-median_sample-mean_unit-mean-v1` として結果に記録します。

1つの視野が複数の条件や実験単位にまたがる配置は受け付けません。対応のない比較で、同じ実験単位が両方の群に入る配置も同様です。実験単位が独立であることは、研究者が確認します。

### 検定
| 目的 | 手法 | 出力 |
|---|---|---|
| 2群、対応なし | Welch の t 検定 | 平均の差、95%信頼区間、t、自由度、p |
| 2群、対応あり | 対応のある t 検定 | 差の平均、95%信頼区間 |
| 2群、順位による | Mann–Whitney U 検定 | U、p、優越確率 |
| 対応あり、順位による | Wilcoxon 符号付き順位検定 | 統計量、p、順位双列相関 |
| 3群以上 | Welch の分散分析、Kruskal–Wallis 検定 | 全体の検定に加え、事前に宣言した2群比較 |
| 関連 | Pearson、Spearman | 実験単位ごとに対応させて計算し、3点以上を要する |

- **p 値の計算**：標本が小さい場合は、すべての並べ方を数え上げる正確な方法で求めます。数え上げが多すぎる場合は、固定した乱数で9,999回並べ替えて求めます。
- **多重比較**：宣言した比較の組に Holm 法で補正をかけます。
- **検定の選び方**：正規性の検定の結果によって手法を切り替えることはしません。研究者がデザインに合わせて選び、デザインに合わない組み合わせは受け付けません。
- **最小の標本数**：1群あたり2単位です。5単位未満では警告を表示します。
- **数値の確認**：主な計算は、手計算で得られる値や、すべての組み合わせを数え上げた値と照合するテストで確認しています。

### 実装していないもの
- 混合効果モデル
- 3条件以上の反復測定に対する全体検定（Friedman、反復測定の分散分析）
- 事後検定（Tukey、Dunn など）
- 標準化効果量（Cohen の d など）
- 相関係数の信頼区間
- FDR 補正
- 同等性の検定
- 検出力の計算
- 計数や割合に特化したモデル

従来の画面には、細胞単位の回帰で視野ごとにまとめて誤差を推定するモデル（探索用）があります。帰無仮説のもとでの模擬実験では、第1種の過誤が約32%（名目は5%）でした。このため、自動で作る解析案には含めていません。

### 言語モデルによる解析案（任意）
解析手順の案を外部の言語モデル（GPT-6.1 Sol）に求める機能です。

- **送るもの**：チャンネルの記号、記録済みの染色名、件数、利用者が入力した目的文だけです。画素・測定値・ファイル名は送りません。
- **既定の状態**：無効です。有効にした場合も、送信のたびに利用者の同意が必要です。
- **返答の扱い**：返答は決められた選択肢の中からだけ選ばれ、手元で科学的な条件を検査します。
  - たとえば、番号だけのチャンネルに染色名を付ける案や、実験単位がないのに検定を行う案は、受け付けません。
  - 検査を通った案も、採用するまでは実行しません。
- **計算は行わない**：モデルは測定値や統計量を計算しません。

## 5. 図の出力

### 描画
図はすべてワーカーが Matplotlib で描き、同じ入力からは同じファイルができるようにしています。画面上の図は、保存済みの値から描いた確認用の表示です。

### 図の種類
| 図 | 表示する内容 |
|---|---|
| 視野ごとの分布図 | 細胞ごとの値と、視野の中央値。比較は行わない。視野が多い場合はページに分け、縦軸をそろえる |
| 群の比較図（従来） | 細胞・視野の中央値・実験単位の値・実験単位の平均±95%信頼区間を重ねる（SuperPlot 型） |
| 群の比較図（新しい画面） | 実験単位の値を、点・対応線・箱ひげ・バイオリン・ヒストグラムのいずれかで示す |
| 関連の図 | 実験単位ごとの X と Y の散布図 |

p 値や有意差の記号は図の上には描かず、図の説明文と CSV に記載します。

### 書式
- **寸法**：Nature の1段幅（89 mm）・2段幅（183 mm）の設定と、任意の寸法を選べます。
- **文字**：Arial 系の書体を使い、日本語は Noto CJK などを使います。字形の欠けや文字の重なり・はみ出しは描画時に検査します。
- **配色**：色覚の違いに配慮した7色と、9種類の記号の形を使います。

### 出力形式
| ファイル | 内容 |
|---|---|
| SVG | 文字を編集できる |
| PDF | 書体を埋め込む |
| PNG | 300 dpi |
| CSV | 各階層の値、欠測の一覧、比較結果 |
| 図の説明文・Methods | 手法と版番号を記載した文章 |
| ImageJ ROI | 領域を ImageJ で開ける形式 |
| 一式（zip） | 上記すべてと SHA-256 の一覧、再計算用スクリプト |

### まだできないこと
- 複数の図を1枚にまとめるレイアウト
- 顕微鏡画像のパネルとスケールバー
- 対数軸や軸範囲の指定
- 配色の変更
- SD・SEM のエラーバー（95%信頼区間のみ）

新しい比較図は実験単位の値だけを示し、細胞や視野の層は描きません。
