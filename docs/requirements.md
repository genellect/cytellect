# Accepted requirements — implementation targets

This contract summarizes the user-approved plan. Implementation status and remaining verification gates are tracked in roadmap.md and validation.md.

## Product

P01: Public genellect/cytellect; own code Apache-2.0; Japanese UI and bilingual README. Clearly separate planned, implemented, tested and scientifically validated.
P02: Free invite-only PoC; no registration, Supabase, billing or paid contracts as initial requirements. An optional LLM analysis proposal follows L01–L06.
P03: DAPI nuclei + NCL nucleolar candidates, manual correction, GFP selection, NCL quantification, group comparisons, GFP association, figures. Group labels are configuration, never private study constants.
P04: Manual ROIs for extranuclear/whole-cell GFP. DAPI does not define cell boundaries. Numeric CSV import supports previously measured RNA/DNA assays.
P05: UBF, RNA FISH, FRAP, 3D/time series, generic spots, automatic cell boundaries and instrument-specific quantification are later recipes.
P06: Publication-ready means editable figures, explicit conditions, traceable measurements, reproducible outputs. Not p-value matching.
P07: The 2026-10-03 extension centers general 2D fluorescence region detection, area/intensity measurement, statistics and figures. Preserve existing nuclear/NCL/GFP recipes and their limits; never transport another stain as GFP/NCL merely to bypass a contract. See [researcher workflow](research-workflow.md) for needs, sequencing and agent responsibilities.
P08: Method support must explain applicability, needed controls, limitations and primary sources. Begin with a no-upload, rule-based planning guide. Unsupported methods are not executable suggestions. No product LLM or additional paid service is required for this phase.
P09: Novice usability means task-oriented choices and a clear next action, with inspectable settings for specialists. Evaluate this through researcher tasks; visual polish and automated browser tests alone do not prove usability.
P11: Ordinary field/channel/tool, tab and analysis-version navigation must not silently discard unfinished regions or experimental metadata. Preserve compatible same-version form state; require an explicit decision before destructive navigation. Never transfer an old revision's draft or quality approval into another revision. Use the same saved field identity and display name throughout image lists, quality review, metadata entry and comparison guidance, including partial analyses.
P10: Versioned planning guidance may be adopted explicitly into a new owned workspace. Recompute guidance on the API, resolve its intended metric and region against actual confirmed inputs, preserve it through immutable edits/exports/replay, and record acknowledged method changes. A plan never supplies actual channel/background/acquisition/independence confirmations. Same-runtime handoff uses memory; cross-runtime handoff uses an explicitly selected local JSON file, not URL or browser storage.

## Workflow and input

I01: Experiment setup → registration → representative trial → edit/review → freeze conditions → batch → QC/selection → statistics/plots → save/delete.
I02: Record group/control, independent unit, sample, field, acquisition date, pairing and optional repeat length; dates and units are distinct.
I03: Native 8/16-bit grayscale channel TIFF and verified single-series OME-TIFF Z=1/T=1; explicit DAPI/NCL/GFP mapping. Reject unknown axes, missing channels, dimension mismatch, corruption and over-limit decompressed pixels.
I04: Missing pixel size means px only. CZI initially converted with Bio-Formats. RGB TIFF is separate compatibility mode.
I05: Immutable original measurement pixels; display LUT and detection preprocessing separate. Native masks canonical at original resolution; store detection coordinate transform.
I06: Background-corrected measurements use a user-confirmed background ROI median. Extranuclear pixels are not automatically background. Save raw/corrected values and preserve native negative corrections. Explicit generic area-only measurement follows A12 without a background ROI. Measurement policy 1.2.0 (`automatic_background`, protocol 4.0.0) is a separate, versioned automatic background candidate recorded as automatic and unconfirmed; it never satisfies or mixes with the confirmed-ROI path, and its failure leaves corrected values missing with a reason (see methods).
I07: Configurable input-security limits 100 fields/workspace, 4096x4096 plane, 3 channels, 2 GiB total. The provisional standard-2g StarDist plane requires both sides ≤2048 px and total area ≤2,700,000 pixels. The specialized native NCL/GFP adapter retains excess rejection. Generic nuclear-only detector protocol 1.1.0 reduces larger detector copies within these bounds and restores integer labels to original coordinates; record shapes, pixel-centre transform, interpolation/rounding and source/restored-mask hashes. Original measurement pixels are never resized. This is not a guarantee of detection accuracy or memory success for every admitted field. Reusing supplied nuclear masks bypasses automatic-nucleus admission, while input/worker limits still apply. Internal IDs for paths, not uploaded filenames.
I09: Generic region entry accepts 1–3 explicitly named 2D grayscale channels with optional metadata and confirmed XY calibration. Missing unit/sample/date remains null. Reusing a channel ID with a different label/stain in the same workspace is rejected. Imported unsigned integer labels retain exact original-coordinate pixel membership. The 1.0 manual/imported recipe stays stable; the 1.1 nuclear recipe requires an explicitly confirmed defining channel and uses only the fixed nuclear model.
I12: Identical image bytes registered under a different client upload key are a separate field; the workspace warns about the duplicate and the researcher decides whether to exclude one. The same key remains idempotent (owner decision 2026-10-06).
I11: Batch registration requires a reviewed field/channel file mapping and explicit metadata application. Do not infer independent units, stain identity or groups from filenames. Scope retry IDs to a workspace and compare accepted file hashes/specification; recover an identical retry without duplicate fields or bytes and reject changed content under the same ID.
Common metadata application must change only explicitly populated columns. Blank common inputs preserve row-specific values. Preview replacement of populated values, allow cancellation and undo of the latest application, and preserve later manual changes, added fields, image mapping and calibration.

## Segmentation, editing and metrics

A01: Real Fiji StarDist2D Versatile fluorescent nuclei. Initial percentiles 1–99.8, probability .5, NMS .3 are starting values requiring validation.
A02: (2026-10-06) The researcher selects the nucleolar definition source: DNA-poor nuclear-stain holes (default, detector 2.0.0) or a stable marker channel such as UBF/FBL; NCL-defined candidates remain only to reproduce existing analyses. Legacy: per-nucleus NCL Otsu + components via ImageJ/MorphoLibJ. Explicit smoothing/size/splitting parameters; DAPI-low auxiliary recipe. No-candidate, ambiguous, failed distinct; nucleus retained.
A03: No whole-nucleus or arbitrary top-fraction substitution for absent native nucleoli. Record circularity limitation of defining NCL regions using NCL itself.
A04: Nucleus/nucleolus IDs and exact containment/parent. Add/delete/reshape/merge/split, Undo/Redo; background and manual ROI. Nuclear changes invalidate affected children and require review.
A05: Native nucleus N, nucleolar union U, nucleoplasm N minus U. In the workspace, U is the adopted (possibly edited) nucleoli revision; nucleoplasm is never re-thresholded or edited directly, and nucleolar edits stay inside one parent nucleus (2026-10-06). Cell nucleolar mean from union pixels, not mean of object means. Separate object table.
A06: NCL area/mean/median/integral for three compartments; nucleolar count/area/fraction; GFP raw/corrected mean/integral and gate reasons.
A07: Native positive corrected values allow nucleoplasm/nucleolus ratio and log2 ratio. Invalid denominator → missing reason, no arbitrary epsilon.
A08: Legacy whole-nucleus/high-NCL log2((nucleus+epsilon)/(high+epsilon)) is distinct metric/recipe. Explicit RGB conversion, resizing, background, clipping, epsilon, gate and version.
A09: Saturation/edge/weak signal/detection/region QC, explicit exclusions. No hardcoded study counts, dates, paths or private results. Revision changes mark existing tables/statistics/figures old.
A10: Expanding a representative trial to a batch explicitly reuses the current reviewed/corrected masks under the unchanged recipe; newly added fields are initialized separately. Reject stale sources, omitted source fields and implicit definition changes. Background or exclusion changes trigger new measurement revisions without discarding corrected masks.
A11: Generic nuclear initialization uses the same pinned Fiji/StarDist model and native coordinates as existing nuclear recipes, without fabricated GFP/NCL channels. Record detector origin separately from whether it ran in the current attempt. Nuclear capacity admission applies only when running the detector. Manual corrections, metadata changes and background recovery reuse canonical masks.
A12: Generic area-only policy 1.0.0 (`mode=area_only`) uses separate measurement/report protocol 2.0.0 and requires an empty background map. Count original-coordinate mask pixels; physical area requires confirmed XY calibration. Raw/corrected intensity and signal-QC fractions stay null with explicit not-requested reasons; intensity selectors are rejected. Preserve native inputs, channel identity, admission checks, exclusions and existing independent/paired statistical requirements. Mode changes create unreviewed children without discarding compatible corrected masks. V1 serialization/fingerprints and bundle `/1` remain unchanged; v2 uses bundle `/2` and Methods 1.2.0. Guide 2.1.0 proposes this mode and resolution 1.1.0 binds the actual choice; old planning 2.0.0/resolution 1.0.0 are not silently upgraded. See [region protocols](generic-regions.md) and [planning](analysis-planning.md).
A13: Private image previews report the exact per-plane display transformation alongside the rendered pixels. Present automatic image/channel scaling and its original-value range beside the image; do not equate similar screen brightness with similar measured signal. Stale or missing previews must not receive a different image's display metadata or accept new graphical edits while loading. Original measurements and review state remain unchanged. See [display conditions](display.md).
A14: Native recipe actions explain incompatibility with the actual acquired channels and registered input mode before submission. Scope representative trials, batches and saved-revision operations exactly as the API does; missing saved snapshots are not replaced by current registration data. Never remove fields, change a method, invent a channel or confirm a negative control automatically. Keep existing control references visible until the researcher explicitly clears them. See [recipe guidance](native-recipe-guidance.md).
A15: A read-only generic-region quality overview exposes existing saved diagnostics for all fields and channels. Distinguish measured diagnostics, unknown acquisition limits, area-only unmeasured signals, empty regions, failure and reasoned exclusion. Deduplicate region counts across channels; keep channel-specific saturation separate. Open the exact saved field/region/channel through the existing source and draft guards. Viewing does not change global review, create per-field approval, exclude data or recalculate measurements. See [quality overview](region-quality-overview.md).
I10: Editing experimental metadata creates an unreviewed child analysis revision. Original upload records, source images and older snapshots remain immutable. Trial-to-batch expansion retains metadata from the adopted parent revision.

Requirement ID clarification (2026-10-04): I10 retains its original experimental-metadata revision meaning from PR #12. The batch-registration requirement introduced in the following increment was also labelled I10; it is now I11. References to the earlier duplicated batch I10 should be read as I11. The requirement text and behavior are unchanged.

## Statistics and deliverables

S01: Confirmed negative-control GFP gate, otherwise manual or batch Otsu labelled exploratory. Never assume a named control is GFP-negative.
S02: Separate cell/field/independent-unit n. Default aggregation field median → sample mean of fields → independent-unit mean of samples. Save method/pairing.
S03: Welch/paired t tests; planned contrast families with Holm correction. Reference and repeat-group families separate. No implicit repeat length zero for reference.
S04: Exploratory group/GFP/date regression, field-clustered SE, GFP association and repeat-length trend. Save transform, date centering, formula, baseline, contrasts and correction family. Detect missing controls, confounding, rank failure, few clusters. Unknown independent replication prevents confirmatory labels.
S05: Sensitivities for GFP gate, NCL high-region definition and complete-comparison dates. Do not silently drop failed fields.
S06: (2026-10-06) Figure text and legends are English only. Original: Matplotlib scatter/regression/95% CI, distributions with unit points, field summaries, adjusted means, paired plots; editable SVG/PDF plus PNG; Japanese/English labels. Figure values correspond to source table and adopted revision.
S07: Measurement/statistics CSV, masks, supported pixel-exact Fiji ROI round-trip, template Methods, environment/config/provenance and replay package. Raw images excluded by default; explicit opt-in only.
S09: First offer a reviewed per-field distribution with observation count, median, quartiles, explicit selection and missingness. One field/one valid observation is sufficient. Independent-unit count stays unknown and no tests/CI/regression are fabricated. Group comparison is a separate explicit action retaining S02–S05. Region/channel/metric identity and source revision must match before export and replay. See [descriptive protocol](descriptive.md).
S10: Generic experimental-unit comparisons explicitly select a region/channel/metric, independent or paired design, treatment unit, acquisition basis and declared Holm comparison family. Build unit/pair coverage from the full source ledger before outcome filtering; retain exclusions and block unexplained empty units/incomplete pairs. Area is channel-deduplicated. No GFP regression, batch adjustment or independence is inferred for generic markers. Source-bound statistics and vectors must regenerate from the original pixels, saved masks and accepted design. See [generic comparisons](region-comparisons.md).
S11: A generic descriptive figure's saved measurement table can open the exact source region, revision and measured channel without CSV lookup. Verify saved mask identity and region membership before selecting it. Preserve unsaved edits; a missing/stale source must not select another object. Area has no measurement channel, so label any image-display channel separately. The browser displays saved values and does not recalculate scientific measurements.
S12: A saved generic comparison exposes its experimental-unit → sample → field hierarchy using the server's saved values and ledgers. Paired membership comes from the saved pair ledger, never row order. Keep excluded and missing inputs visible, and failed-field observation counts unknown. Historical field links verify revision, canonical masks and the actual measurement channel; use the same field display names as the image viewer. Unsaved region/settings/metadata changes prevent navigation. Ambiguous joins disable this inspection without replacing values or hiding saved downloads.
S13: New descriptive requests explicitly select figure policy 2.0.0. Paginate fields at the chosen physical width with one saved vertical scale, stable global field numbers and the complete source tables. Empty fields remain visible. A supported presentation failure may return verified tables with an explicit unavailable-figure state; source corruption, execution failure and cancellation are not successful table-only results. Saved figures and retry requests retain their actual revision and measurement selection. Historical figure requests remain reproducible under their original policy. See [descriptive output](descriptive.md).
S14: New descriptive and generic-comparison Methods identify their own document template, describe the actual recorded measurement and test, and distinguish independent n, observations, fields and complete pairs. Keep complete selection records in their source CSV/JSON, with a concise summary in the prose. Export and replay preserve the saved template; historical documents are not rewritten. Unknown study facts are not inferred. See [statistical Methods](statistical-methods.md).
S15: Browser figure controls expose axis labels, physical dimensions, text size and condition order, retaining the supported descriptive-page widths. Changing these settings marks the displayed result as older than the current settings. Download both actual editable SVG and font-embedded PDF, with the source tables and Methods; a download link alone is not acceptance.
S16: Explicit generic comparison protocol 2.0.0 adds Mann–Whitney U and paired Wilcoxon alongside Welch and paired t tests. Three or more independent conditions require a declared Welch ANOVA or Kruskal–Wallis omnibus, with separately declared planned contrasts and Holm family. Do not select a test from observed significance or a normality pretest. Record assumptions, exact/permutation/asymptotic policy, ties, zeros, random seed and p-value resolution. Historical comparison protocol 1.0.0 remains unchanged.
S17: Generic association protocol 1.0.0 matches two selected measurements by condition and independent experimental-unit identity. Offer Pearson and Spearman with per-condition analysis as the default. Pooling requires explicit confirmation; unmatched unexcluded units block calculation. Preserve both axis source ledgers and report the declared association family. Never infer biological independence from cell or field counts.
S18: Common-statistics plots include distributions with unit points, paired plots, histograms, boxes, violins and association scatter. Preserve observation visibility, units, sample size, documented bin/KDE policies and source-linked SVG/PDF/CSV. New statistics, Methods and figures must replay from the same approved original-pixel measurement source. See [common statistics](common-statistics.md). The actual installed browser workflow, independent numerical references and output review are required before release.

## Local delivery and later cloud execution

L01: Initial low-cost delivery uses the existing browser UI with API/worker on the same PC. Windows setup automates pinned dependencies without modifying system Python or an existing Fiji. Routine startup requires no command or invitation. Installation/browser acceptance precedes an advertised download.
L02: Bind only literal loopback; local session bootstrap is absent from cloud mode. Exact Host/Origin, browser Fetch Metadata, CSRF, HttpOnly cookies and frame restrictions protect browser access. Local OS processes are trusted; this is not shared-account isolation.
L03: The same analysis, revision, measurement, statistics and export contracts serve local and future cloud modes. No local-only scientific fork. Standard Vercel builds do not silently connect to localhost.
L04: Local expiry blocks access after24h; physical deletion while the launcher/PC is off resumes at next launch, disclosed before upload. A future cloud host must satisfy its own continuous deletion and isolation acceptance.
L05: Versioned release bundles contain tracked allowlisted sources and static UI, per-file hashes and a package checksum; no unpublished/private research data, credentials or developer runtime. Registered public demonstration assets retain their redistribution evidence. Git/PR checkpoints record implementation and remaining gates.
