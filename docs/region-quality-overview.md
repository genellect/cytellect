# 全視野の品質一覧

汎用 2D 領域解析の保存済み測定表から、視野ごとの既存の診断を一覧し、確認すべき領域・チャンネルへ戻るための表示。画像の品質、領域の生物学的な同定、採否を自動で判定する機能ではない。

| 項目 | 内容 |
|---|---|
| 対象 | 汎用 2D 領域解析で全視野を測定した研究者 |
| 表示される場所 | 詳細画面の汎用 2D 領域解析で、「測定結果」の下の「全視野の品質一覧」 |
| 元になる情報 | 選んでいる解析版の保存済み測定表と除外記録。画素の測定、背景補正、閾値、統計量は再計算しない |
| 判定しないこと | 品質の良否、領域の生物学的な同定、視野・領域の採否 |

## 1. 表示される項目

| 項目 | 意味 |
| --- | --- |
| 領域数 | 保存されたラベル ID の数。同じ領域の複数チャンネルの行を重複して数えない。細胞数や独立した実験単位の数とは断定しない |
| 画像端 | `touches_border` が保存されている領域。領域ごとに一度だけ表示する |
| 保存形式上限 | チャンネル別の `storage_limit_fraction` が正の領域と、その保存済みの画素割合。撮影装置の飽和とは区別する |
| 取得時飽和 | 利用者が確認した撮影上限に対する、保存済みの画素割合。上限が不明なら「取得上限不明」とする |
| 除外 | 保存済みの視野・領域の除外と理由。診断フラグのある対象と除外済みの対象を分け、フラグのない除外領域も残す |
| 画素サイズ | 保存済みの校正の有無。不明な場合に µm² の値を作らない |

「この診断で該当なし」は、品質が良いという認定ではない。領域 ID は連続しているとは限らず、同じ ID の離れた画素集合も、現行の測定仕様では 1 つの領域として扱う。

## 2. 未測定・欠落・失敗の読み方

| 状態 | 意味 |
| --- | --- |
| 面積のみ（protocol `2.0.0`） | 画像端は確認できるが、輝度と 2 種類の飽和割合は `null`・`not_requested`。ゼロや飽和なしと読み替えない |
| 撮影上限が不明（protocol `1.0.0`） | 取得時飽和を未確認として保持する |
| `no_regions` | 正常に処理され、領域がなかった視野 |
| `failed`・`excluded_failed` | 処理に失敗した視野。別の状態として残し、領域数は不明とする。処理途中のマスクが保存されていても、測定済みやゼロ領域とは推定しない |

失敗した視野では、入力画像の確認と、測定済み領域へのリンクを区別する。

解析版・ポリシー・視野の集合・マスク・チャンネル・除外記録に矛盾がある場合は、一覧を組み立てず「保存済みの品質情報と出典を確認できません」と表示する。別の解析版の結果には置き換えない。この整合の確認は表示に必要な出典の確認で、サーバー側の科学的な入力検証やファイルのハッシュ照合を代替しない。

## 3. 保存済み画像との対応

- 測定済みのリンクは、解析版 ID・視野 ID・領域セット・マスク版 ID とハッシュ・原寸の形状を保持する。マスクを再利用した解析では、解析版 ID とマスク版 ID が異なる場合をそのまま維持する。
- チャンネル別の診断は、保存済みのチャンネル ID・ラベル・標識に対応する。画像端と面積のみのリンクは、測定チャンネルを仮定しない。
- 視野名は画像一覧の表示番号に、条件・試料名は保存済みの解析版の情報に対応させる。保存済みの画像メタデータがあるときは、測定表の形状・校正・チャンネルと照合する。過去の結果にその情報がない場合、現在の入力や未保存のフォームの値で補完しない。
- 領域の未保存の編集・処理中・出典の不一致があるときは、既存の移動制御に従ってリンクを止める。

## 4. 確認の記録

品質確認は、既存の解析版全体の記録をそのまま表示する。一覧の閲覧やリンクの操作で採否は変わらず、視野ごとの確認済みの記録も作らない。個々の視野に必須の確認操作を追加する設計は、この機能に含まない。

## 検証済みの範囲

表示アダプターの単体検証で、既知の保存値による複数チャンネルの重複除去、除外理由、面積のみ・上限不明・領域なし・処理失敗、過去のマスクへの対応、不整合時の表示停止を確認している。これは画像の検出精度、生物学的な妥当性、実際の研究者による操作性評価の証拠ではない。非公開の実画像による M4 と研究者評価の M5 は、引き続き別の受入条件。

## 設計の根拠

[CellProfiler の画像品質測定](https://cellprofiler-manual.s3.amazonaws.com/CellProfiler-4.2.8/modules/measurement.html#measureimagequality)は画像の品質指標を測定し、[QuPath の測定表](https://qupath.readthedocs.io/en/stable/docs/starting/first_steps.html#creating-measurement-tables)は表と画像の対象を対応させる。これらを参考に、既存の診断の一覧から保存済み画像へ戻れる導線を採用した。Cytellect で作業時間が減るという効果は現時点では仮説で、人による利用評価を実施したという主張ではない。
