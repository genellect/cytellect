# 全視野の品質一覧

汎用2D領域解析の保存済み測定表から、視野ごとの既存診断を一覧します。領域・チャンネルの確認先へ戻るための表示であり、画像の品質、領域の生物学的同定、採否を自動判定する機能ではありません。

## 何を表示するか

| 情報 | 表示上の意味 |
| --- | --- |
| 領域数 | 保存されたラベルIDの数。同じ領域の複数チャンネル行を重複して数えない。細胞数や独立実験単位数とは断定しない |
| 画像端 | `touches_border` が保存されている領域。領域ごとに一度だけ表示する |
| 保存形式上限 | チャンネル別の `storage_limit_fraction` が正の領域と、その保存済み画素割合。撮影装置の飽和とは区別する |
| 取得時飽和 | 利用者が確認した撮影上限に対する保存済み画素割合。上限不明なら「取得上限不明」とする |
| 除外 | 保存済みの視野・領域除外と理由。診断フラグのある対象と除外済み対象を分け、フラグのない除外領域も残す |
| 画素サイズ | 保存済み校正の有無。未知の場合に µm² の値を作らない |

一覧は測定表の値を参照し、画素の測定、背景補正、閾値、統計量を再計算しません。「この診断で該当なし」は品質良好の認定ではありません。領域IDは連続しているとは限らず、同じIDの離れた画素集合も現行の測定仕様では一領域です。

## 未測定・欠落・失敗

面積のみの protocol `2.0.0` は画像端を確認できますが、輝度と二種類の飽和割合は `null`・`not_requested` です。ゼロや飽和なしへ読み替えません。protocol `1.0.0` の撮影上限不明も、取得時飽和の未確認として保持します。

`no_regions` は正常に処理され、領域がなかった視野です。`failed` と `excluded_failed` は別の状態として残し、領域数を不明とします。処理途中のマスクが保存されていても、測定済みやゼロ領域とは推定しません。失敗視野の入力画像の確認と、測定済み領域へのリンクは区別します。

解析版・ポリシー・視野集合・マスク・チャンネル・除外記録に矛盾がある場合は、品質一覧を組み立てず「保存済みの品質情報と出典を確認できません」と表示します。別の解析版の結果へ置き換えません。この整合確認は表示に必要な出典の確認であり、サーバーの科学的入力検証やファイルのハッシュ照合を代替しません。

## 保存済み画像との対応

測定済みのリンクは、解析版ID・視野ID・領域セット・マスク版IDとハッシュ・原寸形状を保持します。チャンネル別診断は保存済みのチャンネルID・ラベル・標識に対応し、画像端と面積のみのリンクは測定チャンネルを仮定しません。マスクを再利用した解析では、解析版IDとマスク版IDが異なる場合を維持します。

視野名は画像一覧の表示番号に対応させ、条件・試料名には保存済み解析版の情報を使います。保存済み画像メタデータがあるときは測定表の形状・校正・チャンネルと照合します。歴史的な結果にその情報がない場合、現在の入力や未保存のフォーム値で補完しません。領域の未保存編集・処理中・出典不一致を守る既存の移動制御を利用します。

## 確認記録と検証範囲

品質確認は既存の解析版全体の記録をそのまま表示します。一覧の閲覧やリンク操作で採否を変更せず、視野ごとの確認済み記録も作りません。個々の視野に必須の確認操作を追加する設計は、この機能には含みません。

表示アダプターの単体検証では、既知の保存値による複数チャンネルの重複除去、除外理由、面積のみ・上限不明・領域なし・処理失敗、履歴マスクへの対応、不整合時の表示停止を確認します。これは画像の検出精度、生物学的妥当性、実研究者による操作性評価の証拠ではありません。非公開実画像の M4 と研究者評価の M5 は引き続き別の受入条件です。

## 設計根拠

[CellProfiler の画像品質測定](https://cellprofiler-manual.s3.amazonaws.com/CellProfiler-4.2.8/modules/measurement.html#measureimagequality)は画像の品質指標を測定し、[QuPath の測定表](https://qupath.readthedocs.io/en/stable/docs/starting/first_steps.html#creating-measurement-tables)は表と画像の対象を対応させます。これらを参考に、既存診断の一覧から保存済み画像へ戻れる導線を採用しました。Cytellect で作業時間が減るという効果は現時点では仮説であり、人間の利用評価を実施したという主張ではありません。
