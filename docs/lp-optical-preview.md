# LP のデザイン記録

公開サイトのトップページ（LP）の設計を記録する正本です。方針の要約は [Interface direction](interface-design.md) の「Public website」にあります。実装は `apps/web/src/components/PublicLanding.tsx`（構成と文言）、`optical-landing.module.css`（トークン、ヘッダー、Hero、3D 背景、フッター）、`landing-sections.module.css`（Hero より下のセクション）、`ProductVideo.tsx`（製品映像）、`OpticalHero.tsx` と `optical-scene-engine.ts`（3D 背景）です。

## 方針

- 明るい光学空間を世界観の軸にします。Blender で作った透明な構造・金属・床面の GLB を Three.js で背景に描画し、カメラはスクロールに追従します。細胞写真、渦、顕微鏡や論文の図解を背景のモチーフにしません。
- 構成は、主要な SaaS の LP（Linear、Stripe、Vercel、Notion、Figma、科学分野では Benchling、BioRender）の型に沿います。最初の画面で製品が動いて見え、約束を一文で示し、製品の場面を順に見せ、検証した数字、試せる入口、信頼、提供形態、最後の行動喚起へ進みます。
- 文言は大胆に書いてよいが、数字と科学的な主張は確認済みの事実だけを使い、出典へリンクします。
- 本文は浮かんだ明るいシート（角丸のスライドガラス）に載せ、3D 空間はシートの外側と Hero・最後の行動喚起で見せます。数字だけを暗いシートに置きます。

## 素材

- Hero の製品映像は `landing-media.ts` が選びます。`/marketing/showcase-hero.mp4` と `/marketing/showcase-hero.webp` が揃っていればそれを使い、無ければ記録済みの `/marketing/workspace-public.mp4`（スマートフォンでは `workspace-public-mobile.png` の静止画）を使います。判定はビルド時で、ブラウザは存在しないファイルを要求しません。
- `showcase-hero` は公開デモ（`/demo`）を登録済みの公開画像だけで操作して収録します。目安は 1600×1000（16:10）、H.264・音声なし、20〜30 秒のループ、2.5 MB 以下、同じ寸法の WebP ポスターです。追加するときは `provenance.json` と `fixtures/public/allowlist.json` に収録方法・ハッシュ・元のリビジョンを同じ変更で記録します。
- 素材写真（ストックフォト）は使いません。以前の 3 枚は削除しました。
- 3D 背景の作者、生成スクリプト、素材ハッシュは `apps/web/public/marketing/optical-provenance.json` に記録しています。

## 動きと代替表示

- Hero の文字は読み込み時に一度だけ立ち上がります。他のセクションにスクロール連動の演出は付けません。
- 製品映像は画面内にある間だけ再生し、OS の省モーション設定では自動再生しません。停止・再生のボタンを常に置き、読み込みに失敗したときは同じ静止画を残します。
- 3D 背景は省モーション設定、タブ非表示、停止ボタンで止まり、GLB の取得・解析に失敗したときは静止画を表示します。

## 確認範囲

1440、1280×720（行動喚起が最初の画面に入る）、820、390、360 の各幅で、横はみ出し、3D 背景の上の文字の読みやすさ、フォーカス表示、キーボード操作、省モーション、WebGL と映像の失敗時の表示を確認します。自動テストは `apps/web/tests/marketing.spec.ts`、`lp-viewport-review.spec.ts`、`lp-analytics.spec.ts` です。

日本語フォントは LP の文言から作ったサブセットです。文言に新しい文字を加えたときは `scripts/build_marketing_media.py --fonts-only` でサブセットを作り直します。

解析ワークスペース、認証・API 設定はこの記録の対象外です。
