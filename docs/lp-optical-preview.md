# LP Previewのデザイン基準

今回の到達点は、リアリティのある動く3D空間と、読みやすい文字・CTAを一体化したLP。Lilaは映像、光、余白、タイポグラフィの品質の参照先であり、その素材や画面を複製しない。

## 変えない基準

- 既存の文章、CTAの行き先、おおよその情報順序を保つ。
- サイエンスと未来を感じさせる世界観をLP全体で構成する。
- 立体の質感だけでなく、文字の色・配置・大きさ、セクションの余白も同時に調整する。
- 背景は実際に動く3D。静止画は省モーション設定やWebGL失敗時の代替とする。
- 細胞写真、渦、顕微鏡や論文の直接的な図解を背景のモチーフにしない。
- 明るく読みやすい方向を維持する。単色背景にオブジェクトを置いただけの構成で終わらせない。

## このPreviewの実装

Blenderで作成した透明な構造、金属、床面を一つのGLBへ出力し、Three.jsでページの背景として描画する。カメラはスクロールに追従し、静止中も視点・光・一部の構造が緩やかに動く。背景の停止、OSの省モーション設定、タブ非表示時の停止に対応する。

LP専用のCSSでヘッダー、Hero、本文、実際の製品画面、図、ガイド、ダウンロード欄を組み直す。実験風景と製品画面の既存素材は本文の説明用として保持する。背景の作者、生成スクリプト、素材ハッシュは `apps/web/public/marketing/optical-provenance.json` に記録する。

## 確認範囲

PC、タブレット、スマートフォンで文字と背景の重なり、CTA、ナビゲーション、横幅を確認する。動く状態と停止状態、GLB取得・解析失敗、省モーション設定をブラウザで確認する。

当初はPreviewまでを対象としたが、Desktopの確認後に所有者がmainへのマージと本番反映を承認した。Desktopの構成を維持し、Mobile Heroの文字・CTA・背景の組み合わせを別に調整する。ヘッダーロゴはURLを変えず、250msで先頭へスクロールする。省モーション設定時は即時移動する。

解析ワークスペース、認証・API設定は今回の対象に含めない。
